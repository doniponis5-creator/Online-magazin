## Как получены кадры

1. **Проверка средств.** Blender/POV-Ray в среде отсутствуют; была начата
   загрузка бесплатного Blender 5.2.1 portable (405 МБ, `.tools/`,
   в git не входит) для процедурной модели — после указания владельца
   («реальные изображения — с официальной страницы») этот путь остановлен:
   кадры строятся из официальной галереи LG, что точнее любого
   собственного рендера.
2. **Официальная галерея.** Со страницы карточки товара скачаны
   оригинальные изображения (2010×1334, JPG) в
   `assets-src/lg-f4x5es5sb/lg-originals/`: фронт (01), высокий угол (03),
  барабан (06), левый ракурс (08), правый (10), нижний левый (12).
   Целостность проверена (sharp: размеры/декодирование).
3. **Выбор кадров** — визуальный осмотр кандидатов:
   - 01 (фронт): машина целиком, чистый светло-серый студийный фон;
   - ¾: **08-left** — видны и фронт, и боковая панель, глубина корпуса и
     двери; машина целиком, тот же студийный фон (10-right частично
     перекрыт бликами, 12 — нижний ракурс, драматичнее, но менее
     «каталожный»);
   - внутренний: **06-drum** — реальный интерьер барабана LG
     (нержавеющий барабан, подниматели, перфорация).
4. **Обработка** (sharp): 01/02 — только ресайз 2010→1600 px (одинаковая
   обработка и соотношение 3:2, без обрезки машины, без наших надписей в
   изображении — требование кадра 01 соблюдено). 03 — фото барабана +
   наша тонкая векторная аннотация (линии/точки #245BEB/#7fb32a):
   подниматели (6 Motion DD), перфорация, Direct Drive за барабаном;
   кадр остаётся реальным снимком с демонстрационной разметкой, подпись
   «Схематичная демонстрация технологии» вынесена в лист просмотра.
5. **Самопроверка глазами** (все PNG открыты и осмотрены): корпус цел во
   всех кадрах; пропорции и материалы совпадают между 01 и 02 (одна
   студия производителя); аннотации 03 указывают на реальные зоны
   (проверены по верхней/нижней половине кадра); искажений, обрезки,
   посторонних объектов нет. Фронтальный кадр сверен с референсом
   владельца (`reference/lg-f4x5es5sb-owner-reference.png`): тот же
   серебристый корпус, чёрная панель с центральным переключателем,
   крупная тёмная дверца, сервисная крышка — соответствие узнаваемое.

## Что готово и что нужно для анимации (следующий этап)

Готово: три согласованных статичных кадра для дизайн-ревью — задача
этого этапа выполнена без скролл-интеграции и без замены текущей витрины.

Для будущего scroll-этапа честно: это **три отдельных официальных снимка**,
не непрерывная 3D-модель — непрерывное вращение из них не получится;
возможные пути: (а) кроссфейд/параллакс между этими кадрами под скролл
(дёшево, но «поворота» не даст), (б) полноценная 3D-модель (Blender уже
загружен локально в `.tools/`, скрипт-модель + рендер последовательности),
(в) официальный 360°-обзор LG, если он есть для этой карточки — нужно
отдельное указание владельца, что считать приоритетным. Воду/физику
не имитировали (в задании — не делать).

Код магазина в этой задаче не менялся; полный набор его тестов не
запускался (по условиям задачи не требуется). Большие бинарники в git
