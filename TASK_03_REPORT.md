## 1. Закрытие оставшихся ошибок (до визуальной переработки)

- **ProductDetail fallback убран.** `comboVariant() ?? product.variants[0]` удалён:
  если комбинации нет — цена не показывается, добавление заблокировано (кнопка
  «Нет в такой комбинации»), чужой SKU невозможно добавить даже программно.
  Покрыто браузерным тестом
  `product-zoom.spec › variant combo: missing combination is explicit…`
  (демо-каталог TabSlate намеренно не содержит комбинацию «Тёмный · 256 ГБ»).
- **Предсказуемый выбор характеристик.** Смена цвета/памяти больше не «молча»
  меняет вторую характеристику (авто-подбор `pickMemoryForColor`/`pickColorForMemory`
  удалён). При недоступной комбинации показывается явное состояние
  «Нет в такой комбинации» + список доступных комбинаций — переход только явным
  действием пользователя. Тест проверяет, что память осталась «256 ГБ» и что
  предложение переключает на «Тёмный · 128 ГБ» по клику.
- **Доступный зум.** Галерея переведена на нативный `<dialog>` + `showModal()`:
  фон инертен (фокус и клики недоступны), Tab/Shift+Tab остаются в диалоге,
  Escape и крестик закрывают, фокус возвращается на opener, прокрутка фона
  блокируется (`html.dialog-open`) и восстанавливается. Тест
  `zoom: focus trap, Escape, focus return, scroll lock` проверяет все пять условий.
- **Корзина: уведомления.** Флаг корректировки больше не теряется: сообщение
  показывается и когда удалены все строки, и когда JSON повреждён — отдельный
  текст «Сохранённая корзина была повреждена…» / «Сакталган себет бузулган…».
  Новые e2e: `cart notice: shows even when restored cart lost all lines`,
  `cart notice: corrupted JSON gets a dedicated message`.
- **Синхронизация двух вкладок проверена** (storage-события): корзина
  (`two tabs: cart added in one tab appears in the other`) и избранное
  (`two tabs: favorites toggled…` — добавлен storage-обработчик в FavoritesProvider).
  Это клиентский комфорт прототипа, а не защита платежа.

## 4. Анимации — единая система токенов

`globals.css`: `--dur-hover 160ms`, `--dur-press 140ms`, `--dur-swap 240ms`,
`--dur-reveal 320ms`, `--dur-img 180ms`, ease-out/spring.

- hover карточки: подъём 2px + тень + лёгкий zoom фото (transform-only, 160ms);
- press: scale .98 (140ms), у тач-устройств hover-залипания нет (нет hover-only логики);
- добавление: кнопка «В корзину» превращается в количество (swap 240ms) прямо
  на карточке; confirmation «Добавлено» с `aria-live="polite"`;
- favorite: однократная мягкая пружина `fav-pop` (320ms, только при активации);
- секции: однократное появление 320ms при входе в вьюпорт (`MotionProvider` +
  IntersectionObserver, `data-reveal`); без JS контент виден сразу;
- смена изображения SKU: fade 180ms;
- `prefers-reduced-motion`: transform/reveal отключаются (глобальный override +
  MotionProvider не запускает наблюдатель), все действия остаются.
- Запрещённое не вводилось: нет autoplay-каруселей, scroll hijacking, параллакса,
  бесконечной пульсации, animation-зависимостей (только CSS + маленький observer).

Запись анимаций: `review/task-03/animation-add-to-cart.webm` (reveal-скроллы и
превращение кнопки в количество). Вручную дополнительно проверены: hover
карточки, зум-открытие (150–220ms фазовый fade), фокус-кольца.
