# ASSET_SOURCES — источники визуальных материалов

Прототип Smart Centr, milestone 01/02 (11.09.2026).

## Изображения товаров

- **Что используется:** оригинальные схематичные SVG-иллюстрации, нарисованные
  специально для этого прототипа (`src/components/ProductArt.tsx`: телефон,
  ноутбук, планшет, телевизор, наушники, стиральная машина, кофемашина,
  аэрогриль, робот-пылесос, часы, колонка).
- **Лицензия:** собственная графика проекта, внешних заимствований нет.
- **Ограничение (честно):** это НЕ фотографии конкретных моделей. Иллюстрации
  носят явно маркированный демонстрационный характер («Демо-товар») и не
  выдаются за внешний вид продаваемых товаров. Реальные фото появятся только
  после получения материалов от производителя/поставщика с подтверждённым
  правом использования (ARCHITECTURE_UZ.md, §12); тогда этот файл будет
  дополнен: источник, модель, основание использования для каждой фотографии.

## Иконки интерфейса

- `src/components/Icons.tsx` — оригинальные линейные SVG-иконки, нарисованные
  для проекта (поиск, корзина, избранное, доставка и т.д.). Внешних наборов
  не используется.

## Прочее

- Шрифты — системный стек (system-ui/Segoe UI/Roboto/Inter), внешних
  веб-шрифтов не подключается, лицензионных загрузок нет.
- Концепт-референс дизайна: `reference/smart-centr-concept.png` (предоставлен
  владельцем проекта), использован как композиционный ориентир.
- Внешние CDN, стоковые фото, AI-сгенерированные изображения товаров —
  не используются.
