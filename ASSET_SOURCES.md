## Текущий контракт (решение владельца 12.09 + brief LG F4X5ES5SB)

- **Активных фотографий в витрине нет.** Hero — авторская CSS-сцена
  «LG F4X5ES5SB» (серебристая машина, фазы TurboWash™360° и Inverter Direct
  Drive, управляются коротким участком обычной прокрутки; подробности — в
  TASK_03A_REPORT.md). Сцена — графика проекта, не фото и не CAD производителя.
- **Товарные фото не показываются**: карточки, каталог, избранное, страница
  товара, корзина и checkout используют единый нейтральный плейсхолдер
  «Фото скоро появится» / «Сүрөт жакында чыгат». Реальные модели и снимки
  предоставит владелец; тогда они будут оформлены в едином стиле.
- **Фотозум без снимка не открывается**; доступный нативный `<dialog>`
  сохранён для будущих фото и проверяется изолированной фикстурой
  `/dev/gallery?fixture=zoom` (без параметра — 404, в витрине не связан).
- Подтверждённые характеристики LG взяты только с официальной страницы
  (11 кг, AI DD / AI Wash, инверторный прямой привод, TurboWash360°, Steam,
  6 Motion DD, ThinQ); цена/остаток/покупка для LG не имитируются.

## Запрос магазину: фото для будущего каталога 1С

Для дизайн-проверки и запуска нужны фотографии **реальных моделей/артикулов
из будущего каталога 1С** (права согласованы с поставщиками), по каждому
товару: прямой снимок на светлом фоне (фронт + 3/4), снимок каждого варианта
(цвет/память), крупная техника целиком, единый масштаб/фон сетки. Вымышленные
демо-имена (Aura/Vega/…) — заглушки, их «фотографий» не запрашивать.

## Технические заметки

- Хранение: активный баннер — статический импорт из `src/assets/`;
  архивные файлы — `public/photos/` (не раздаются витриной).
- Выдача: `next/image`; hero — `priority`, плейсхолдеры — чистый CSS/SVG
  без сетевых запросов.
- `scripts/fetch-photos.mjs` (Openverse) — исторический инструмент первого
  поколения, актуальный набор им не воспроизводится.
