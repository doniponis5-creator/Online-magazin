# /banner — баннер на главную за один заход

Владелец пишет одной фразой («баннер: холодильники со скидкой», «Kemal Usman баннерини алмаштир», «3-баннерни ўчир»).
Не переспрашивай — выбери разумно сам, покажи готовое, поставь. Отвечай как он пишет (узбекская кириллица/латиница,
русский), по схеме: что сделал · сработало или нет · что ему делать дальше.

Токены беречь: НЕ читай `make_banners.py`, `upload_banner.py`, CLAUDE.md и граф — всё нужное ниже. Картинки смотри
только готовые (2 файла), каждую один раз.

## 0. Где

Корень проекта: `git rev-parse --show-toplevel`; не в git — `D:\Projects\Online-magazin`. Сначала `git pull`.
Все команды — из корня, через Bash. Только PC (Windows): 1С и COM есть только там.

## 1. Товары (если баннер про товары)

```
python scripts/banners/make_banners.py --find "холодильник"
```
Печатает `ЦБ-код  название · раздел · цена (было …) · остаток`. Бери 3 товара в наличии (остаток > 0, цена > 0),
для скидок — со «было». Первый код — крупный в середине. Владелец назвал коды — бери их.

## 2. Нарисовать

```
python scripts/banners/make_banners.py --name 5-holodilniki --bg blue --chip "Скидки недели" \
  --title "Холодильники со скидкой" --cta "Смотреть" --codes ЦБ-1,ЦБ-2,ЦБ-3 [--badge "−%"]
```
- `--name` — латиница, номер вперёд: следующий свободный (`--list` в шаге 4 покажет, сколько стоит).
- `--bg`: `lemon` (рассрочка, акции) · `blue` (техника, зима) · `cream` (парфюм, уют) · `grey` (скидки) · `mint` (дом,
  кухня) · `rose` (подарки, праздник).
- Текст ТОЛЬКО по-русски, без цен и без киргизской строки. Заголовок ≤ ~30 знаков; `|` — свой перенос, `~` — пробел
  без переноса (бренды: `Kemal~Usman`). Кнопка 1–2 слова, стрелку `›` скрипт ставит сам. Плашка `--chip` — коротко
  или не нужна.
- `--badge`: `"−%"` для скидок, `"Хит"`, `"Новинка"` — наклейка на главном товаре.
- Своё фото вместо товаров (владелец прислал картинку — путь из сообщения): `--photo <путь>`; на телефоне фото
  режется полосой сверху — если отрезало голову/логотип, `--phone-top 0`.
- Знак партнёра (рассрочка): `--mark mislamic.png` (только с `--codes`).

Готово: `review/banners/<name>-desktop.jpg` и `-phone.jpg` (в git не идут, не коммить).

## 3. Проверить (обязательно, глазами)

Открой Read обе картинки. Ищи: текст налез на товар/фото, кнопка обрезана краем, на телефоне большая пустота,
не тот товар. Есть изъян — поправь ключи и перерисуй. Пошли владельцу обе (SendUserFile, display render).

## 4. Поставить на сайт (рабочая 1С)

```
python scripts/banners/upload_banner.py --list
python scripts/banners/upload_banner.py 5-holodilniki --title "Холодильники со скидкой" --link "Холодильники" --yes [--pos 1]
```
- `--link` («куда ведёт»): раздел по-русски (`Холодильники`, `Энергоснабжение`) · код `ЦБ-00001882` · страница
  `/ru/catalog?sale=1` (скидки), `/ru/catalog?inst=1` (рассрочка) · `https://…` (другой сайт).
- Тот же `--title`, что у стоящего баннера → меняются только картинки (ссылка и место прежние) — так «обновить баннер».
- Баннеров не больше 10. Выключить: `--off ID`, включить: `--on ID`, удалить: `--remove ID` (ID — из `--list`).
- Пароль 1С скрипт берёт сам из `.env.local`. Свои пароли не вводи, из чата — не используй.
- `--yes` — только когда владелец сам попросил поставить/заменить/убрать. Если инструмент отказал в запуске
  (рабочая база) — не обходи: дай владельцу ровно эту команду в блоке ```bash, он запустит сам.
- `--test` НЕ безопасная песочница: тестовая копия смотрит на тот же боевой сервер.

## 5. Убедиться, что на сайте

Через ~1 мин (сайт держит ответ 60 с): md5 картинки компьютера есть в главной.
```
md5sum review/banners/<name>-desktop.jpg
until curl -s "https://smarket.kg/ru?b=$RANDOM" | grep -q <md5>; do sleep 10; done   # через Monitor, не дольше 3 мин
```
Пропало всё на минуту — сайт разово не достучался до сервера и показывает автоматические слайды; ждать, вернётся.

## Сломалось

- `товара … нет на сайте` — товар не выгружен или без фото: другой код из `--find`.
- `сервер не принял картинку` — размер/пропорции (компьютер ≥ 1200 px, 1,6–4 : 1; телефон ≥ 600 px, 0,6–1,5 : 1):
  баннер встал без неё — перерисуй и запусти шаг 4 с тем же `--title`.
- `на сайте уже 10 баннеров` — спроси владельца, какой убрать (`--list`), это его решение.
- Нужно другое оформление, а не новый баннер (шрифт, раскладка) — это правка `scripts/banners/make_banners.py`:
  покажи владельцу до/после, коммить только после «ha».
