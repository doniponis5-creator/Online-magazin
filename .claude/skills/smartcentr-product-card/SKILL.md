# Карточка товара Smart Centr — за один заход

`/smartcentr-product-card <название или фото>` — сделать один товар молча. Спросить можно только одно: какой товар,
если в 1С несколько похожих. Без промежуточных сообщений. Только PC (Windows, 1С по COM).

Токены беречь: НЕ читай CLAUDE.md, граф, исходники скриптов; без скриншотов, аудитов, тестов, git, повторных проверок —
только если что-то упало.

Скрипты: `S=.claude/skills/smartcentr-product-card/scripts` (в git). Команды — через Bash из корня проекта
(`git rev-parse --show-toplevel`; не в git — `D:\Projects\Online-magazin`). Пароль 1С скрипты берут сами из
`.env.local`; пароли из чата не вводить и не использовать.

## 1. Найти в 1С
`python $S/find_product.py "<слова из названия>"` → `[{code, name}]`. Берём точный код и точное имя 1С.
Пусто — короче запрос (модель без бренда). Несколько разных моделей — один вопрос владельцу.

## 2. Факты
Сначала то, что дал владелец (фото коробки, наклейки, его слова). Не хватает — один WebSearch по точной модели,
не больше двух надёжных источников (производитель, крупный магазин). Ничего не выдумывать: нет данных — нет строки.

## 3. Текст (по-русски)
Описание 2–3 предложения: что это и чем полезно покупателю, без воды и восклицаний. Характеристики — только
полезные покупателю, 5–15 строк, единицы как на сайте («1,7 л», «2000 Вт», «60 × 85 × 60 см»).
Файл `integrations/1c-online-shop/site-texts/<ГГГГ-ММ-ДД>-<код>.json`:
```json
[{"code": "ЦБ-…", "name": "<точное имя 1С>", "description": "…", "specs": [["Мощность", "2000 Вт"]],
  "sources": ["https://…"], "note": "что взято у владельца"}]
```

## 4. Фото — три, именно эта модель
Спереди на белом · под углом · внутри/в работе. Сначала фото владельца, потом чистые фото производителя/магазинов
(WebFetch страницы → адрес картинки → curl в `review/product-card/src/`). Без надписей, водяных знаков, чужих логотипов,
лишних деталей. Не та модель/цвет — не брать. Рисовать или генерировать фото нельзя (инструмента нет и это была бы
неправда о товаре). Нашлось меньше трёх — ставь сколько есть и скажи владельцу, каких не хватает (лучше всего — пусть
снимет в магазине телефоном: спереди, под углом, внутри).

Фото не на белом (магазин, прилавок, рука, чужой фон) → белый квадрат 1200×1200, товар по центру:
`~/.claude/venvs/rembg/Scripts/python.exe $S/clean_bg.py review/product-card/<код>/white фото…`
(rembg на этом компьютере, без интернета; нет папки — `python -m venv ~/.claude/venvs/rembg` и
`~/.claude/venvs/rembg/Scripts/python.exe -m pip install "rembg[cpu]"`; оставляет одно самое крупное — продавец и соседние товары уходят). Тёмный
товар на тёмном фоне, стекло, товар в руке вырезаются плохо — такую картинку не брать.

Каждую готовую картинку перед записью открой Read один раз — тот ли товар, цел ли он, нет ли кусков фона.

## 5. В рабочую 1С (каждый скрипт: сначала проверка, потом запись)
```
python integrations/1c-online-shop/fill_site_texts.py integrations/1c-online-shop/site-texts/<файл>.json prod
python integrations/1c-online-shop/fill_site_texts.py integrations/1c-online-shop/site-texts/<файл>.json prod --apply
python $S/set_photos.py <код> --name "<точное имя 1С>" 1.jpg 2.jpg 3.jpg
python $S/set_photos.py <код> --name "<точное имя 1С>" 1.jpg 2.jpg 3.jpg --apply [--replace]
```
- Тексты: описание пишется, только если его не было; характеристики дописываются, свои строки владельца не трогаются;
  копия прежнего — в логах (откат `--undo`). Спрашивает «да» — отвечай `echo да |` перед командой.
- Фото: у товара уже есть фото — `--replace` только если владелец просил заменить или прежние плохие; прежние
  сохраняются в `review/product-card/backups/`.
- Цену, остаток, раздел, название — никогда не менять.
- Инструмент отказал в записи в рабочую базу — не обходить: дать владельцу эти команды в ```bash.

## 6. На сайт
`python $S/publish_catalog.py` — 1С сразу отправляет каталог на сервер. Сайт сам забирает каталог раз в 10 минут и
пересобирается (3–5 мин); SSH не нужен. Ссылка: `https://smarket.kg/ru/product/<код: ЦБ-00001234 → cb-00001234>`.

## 7. Проверка — одна
Через Monitor (не дольше 20 мин): `until curl -s <ссылка> | grep -q "<одно значение из характеристик>"; do sleep 30; done`.
Дождался — готово. Не дождался — так и сказать: «сайтда 15–20 дақиқада чиқади».

## Ответ владельцу — одна строка, узбекская кириллица
`Тайёр — <код> — <ссылка>`; фото меньше трёх — дописать, каких нет. Застряло — одна короткая причина.
