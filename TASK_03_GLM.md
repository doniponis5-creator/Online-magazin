## 4. Анимации — заметное качество, без отвлечения от покупки
Единая система движения в CSS tokens:
- hover кнопки/карточки 140–180ms, небольшой сдвиг тени/изображения без скачка layout;
- press scale .98, 120–160ms; на touch нет зависшего hover;
- добавление товара: короткое подтверждение и превращение действия в количество, 200–280ms; live announcement для screen reader;
- favorite: однократная мягкая пружина/смена заливки, без confetti;
- раскрытие фильтра/галереи 180–240ms;
- баннер/секции: однократное мягкое появление 250–400ms, малое смещение, без исчезающего до JS основного контента;
- переход изображения выбранного SKU 150–220ms, сохранять размер.
Не задерживать реальные действия ради эффекта. Не делать бесконечную пульсацию, autoplay-карусель, scroll hijacking, тяжелые частицы, следование за курсором, параллакс на мобильном. Не вводить animation dependency, если CSS хватает.
prefers-reduced-motion убирает transform/scroll/reveal-движение; все действия остаются понятными. Только transform/opacity где возможно. Проверить мобильную плавность и отсутствие layout shift.
