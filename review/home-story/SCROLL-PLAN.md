# Партитура

| Прогресс | Изображение | Текст |
|---|---|---|
| 0–0.32 | Начальное приближение 1.48, кухня крупнее | Дом просыпается. |
| 0.32–0.70 | Непрерывное уменьшение приближения | Для каждого дела — свой помощник. |
| 0.70–1 | Общий вид, масштаб до 1 | Комфорт начинается дома. |

Один sticky-контейнер, ход 560px на desktop и около 400px на mobile. Все состояния выводятся из абсолютного положения прокрутки, поэтому обратный ход симметричен. Текст меняется целиком на границах интервалов, без наложения. CTA постоянно доступна и ведёт в /[lang]/catalog?cat=home. При reduced-motion — финальное сообщение и общий кадр без закрепления. Без JS — начальное сообщение, общий кадр и ссылка без дополнительного хода. Ошибка изображения сохраняет светлый фон, текст и CTA.
