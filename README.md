# Smart Centr — прототип витрины (milestone 01/02)

Демонстрационный прототип интернет-магазина электроники Smart Centr:
Next.js 16 (App Router) + TypeScript, RU/KY интерфейс, демо-каталог, корзина,
избранное и честное демо-оформление заказа. Архитектура описана в
[ARCHITECTURE_UZ.md](ARCHITECTURE_UZ.md).

## Запуск

```bash
npm install        # зависимости
npm run dev        # разработка → http://localhost:3000
```

Продакшн-сборка и preview:

```bash
npm run build
npm run start -- -p 3100   # → http://localhost:3100
```

Проверки:

```bash
npm run typecheck   # TypeScript
npm test            # unit-тесты (vitest): корзина, SKU, ссылки, i18n
npm run test:e2e    # сценарии (Playwright, нужен Chrome; использует localhost:3100)
```

## Демо-границы (важно)

- Все товары, бренды, цены (сом/KGS), характеристики и остатки — **вымышленные
  демонстрационные данные**, не публичная оферта и не склад 1С.
- Сайт **не подключён** к 1С, SBonus, O!Деньги, банкам, SMS/WhatsApp.
  Никаких реальных оплат, списаний бонусов или отправки заказов.
- Демо-оформление: заявка не отправляется и не сохраняется; финальная сумма,
  доставка и наличие «подтверждаются сотрудником» — это модель будущего
  ночного сценария из архитектуры (§6).
- Изображения товаров — оригинальные схематичные SVG-иллюстрации
  ([ASSET_SOURCES.md](ASSET_SOURCES.md)), не фото реальных моделей.
- Корзина и избранное хранятся только в localStorage браузера.
  Персональные данные (имя/телефон в формах) никуда не пишутся и не сохраняются.

## Структура

```
src/app/[lang]/        страницы: главная, каталог, товар, корзина, избранное, checkout
src/components/        UI-компоненты (Header, ProductDetail, Gallery, …)
src/data/              демо-фикстуры каталога (products.ts, categories.ts)
src/lib/i18n/          словари RU/KY и провайдер
src/lib/cart/          чистая логика корзины + провайдер (нормализация localStorage)
src/lib/cart/sku.ts    подбор варианта-комбинации «цвет + память»
e2e/                   Playwright-сценарии (zoom, корзина, каталог, checkout, overflow)
__tests__/             unit-тесты (vitest)
review/                скриншоты ключевых экранов
```

## Что есть / чего нет

Есть:responsive-витрина (360–1440px), RU/KY с проверенными Ң/Ө/Ү,
поиск/фильтры/сортировка с состоянием в URL (назад/вперёд работают),
варианты товаров (комбинации), галерея с зумом (Escape, клавиатура),
корзина с лимитами и защитой от битых данных, избранное,
демо-checkout и демо-заявка на рассрочку (только для «существующих клиентов SBonus»),
ночной сценарий в текстах, `prefers-reduced-motion`, клавиатурная навигация.

Нет (следующие этапы):реальный backend и интеграция 1С/SBonus/платежей,
авторизация, настоящие фотографии, отзывы, акции, админка,
нативные iOS/Android (сайт спроектирован как переиспользуемая основа,
нативные приложения не заявлены и не готовы).
