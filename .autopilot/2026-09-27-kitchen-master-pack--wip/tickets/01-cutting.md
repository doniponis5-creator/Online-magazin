## Критерии приёмки

- [ ] `cutParts(spec, look)`: детали корпусов из `cutList` (ЛДСП 16 и ХДФ) + фасады из ЛДСП (ламинат) из `frontList`; МДФ-фасады помечены `kind:'mdf'` (в распил не идут); количество деталей совпадает с `cutList`/`frontList` (тест на угловой и П-образной кухне через `buildKitchen` в node, как в `__tests__/kitchen-build.test.ts`)
- [ ] Кромка по правилам истории 4 (видимая кромка корпуса по умолчанию 1 мм, скрытая 0,4, фасады ЛДСП 2; толщина видимой кромки корпуса — параметр `look`/опция); `edgeTotals` — метры по толщине с запасом 10%; тест считает кромку на известной детали вручную
- [ ] `nest`: все детали размещены, не пересекаются, внутри рабочей зоны листа (лист − обрезка), пропил между деталями; детали с `grain` не повёрнуты; деталь длиннее листа — в `oversize`, не теряется; `waste` посчитан по формуле истории 7; число листов ≥ нижней границы по площади (тест-перебор на ≥ 200 кухонях)
- [ ] Материал/цвет/текстура — из выбранной отделки (`finishes.ts`), корпус по умолчанию белый без текстуры
- [ ] `npx tsc --noEmit`, `npx vitest run`, `npm run build` зелёные
