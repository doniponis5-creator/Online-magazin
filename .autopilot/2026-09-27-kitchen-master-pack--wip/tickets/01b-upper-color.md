# 01b — Второй цвет верха, доборы и планки в раскрое

**Требования:** R02, R04
**Blocked by:** 01 (закоммичен), 02 (закоммичен)
**Зона:** `src/lib/kitchen/spec.ts` (поле `upper` у `SpecFront`) · `src/components/kitchen/three/build.ts` (ставит `upper`) · `src/lib/kitchen/cutting.ts` · `src/lib/kitchen/cutExcel.ts` и `src/components/kitchen/texts.ts` (только подписи новых деталей) · тесты
**Волна:** 2 (параллельно с 02 — зоны не пересекаются)
**Status:** ready

## Что должно заработать

Если покупатель выбрал для верхних шкафов другой цвет фасадов (`upperFacade`), в раскрое верхние фасады идут своим цветом, нижние — своим.

## Критерии приёмки

- [ ] `SpecFront.upper: boolean` — `build.ts` ставит для фасадов верхнего ряда и антресолей (включая шкаф над холодильником, если его цвет не задан отдельно `overFridgeFacade`)
- [ ] `CutLook.upperFacade?: string | CutFinish`; `cutParts` красит `upper`-фасады цветом верха (при `upperFacade === 'style'` или без него — как низ)
- [ ] Тест: угловая кухня с `upperFacade` другого цвета — фасады верха своего цвета, низа своего; без `upperFacade` — всё как раньше
- [ ] Цвет верха по умолчанию — тон стиля с `upper` (`styles.ts`, `materials.ts`): у таких стилей верхние фасады в раскрое своим цветом и без `upperFacade`
- [ ] Доборы, планки угла, задняя панель острова (`extraList`: filler, strip, islandBack) — в `cutParts` в цвет фасада/верха, в раскладке листов; кромка: видимые кромки 2 мм как у фасадов ЛДСП (МДФ — в цех фасадов); подписи RU/KY; тест: число листов на кухне с доборами и островом учитывает эти детали
- [ ] Стекло/рамочные — в цех фасадов без утверждения «МДФ»; фасад стиля без материала из каталога — в цех фасадов с пометкой «материал по стилю — уточнить» (спека, Решения §5)
- [ ] Лист «Фасады» строится из самих деталей: у фасада-детали есть высота, ширина и материал отделки (без обратного поиска по `frontList`); фасад без материала/пары — ошибка, а не молчаливый пропуск; МДФ-доборы тоже попадают в «Фасады»
- [ ] Толщина МДФ-фасадов не утверждается «18 мм» (из каталога или не пишется); язык — из одного источника (`t` или `look.lang`, не оба)
- [ ] «Листы»: у повёрнутой детали размеры как в «Распил» + «Повёрнута: да» (или подписи осей листа); пропуски номеров в «Распил» объяснены строкой-пояснением; ширина колонок кромки ≥ 11
- [ ] Мелочи ревью: неизвестный id отделки — явный отказ, не «Белый премиум»; метры кромки «купить» округляются вверх; толщина ХДФ — из одного места; комментарий про Д1/Д2 у деталей с текстурой исправлен
- [ ] `npx tsc --noEmit`, `npx vitest run`, `npm run build` зелёные
