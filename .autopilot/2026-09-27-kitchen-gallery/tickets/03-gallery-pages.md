## Критерии приёмки

- [ ] `/[lang]/kitchen/gallery`: разделы «Готовые кухни» (READY), «Лучшие», «Новые»; фильтр формы и размера («до 2,7 м» / «2,7–4 м» / «больше 4 м»); 24 + «Ещё»; пусто — приглашение; фильтр «мои» (вошедшему) и «кухни мастера» (`?author=`)
- [ ] `/[lang]/kitchen/gallery/[id]` (и для READY — `ready-<id>`): картинка, название, автор (имя, метка «Мастер»), дата, форма/размеры, стиль и цвета (`frontsText` из `order.ts`), техника со ссылками и суммой по текущим ценам («нет в наличии» без ссылки), оценка + число, «Хочу такую же» → `/[lang]/kitchen?<q>`, «Поделиться», комментарии и форма, «Пожаловаться», «Я сделал такую» (фото, автору; фото показываются рядом с 3D-кадром — «В 3D» / «В жизни»), «Убрать из галереи» (автору); скрытая/нет — 404
- [ ] (история 21a) у карточки с фото «в жизни» — метка «Есть фото вживую» и маленькое фото в углу 3D-кадра; фильтр «Только с фото вживую»
- [ ] вход для оценки/комментария — тот же, что в кабинете (`CustomerLogin`, `useCustomer`); после входа действие продолжается
- [ ] метаданные: title/description, canonical, RU/KY alternates, `openGraph.images` = карточка кухни; `sitemap.ts` — галерея, READY и опубликованные кухни (не скрытые)
- [ ] тексты RU/KY — `src/lib/gallery/texts.ts`; ошибки API (`login`, `too-many`, `bad-input`, `not-found`, `forbidden`) — понятными словами, введённый текст не пропадает
- [ ] телефон 375×812: 1–2 колонки, звёзды и форма удобны, без горизонтальной прокрутки; проверка в браузере (headless, `--disable-3d-apis` можно — страницы галереи 3D не рисуют), RU/KY
- [ ] тесты: разметка карточки/страницы без телефонов, sitemap без скрытых; `npx tsc --noEmit`, `npx vitest run`, `npm run build` зелёные
