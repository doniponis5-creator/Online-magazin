## Что должно заработать

Класс устройства выбирается один раз (`desktop`, `desktop-weak`, `phone`, `phone-low`), переключателя качества и ключа `kp-quality` в localStorage нет (планировщик в этом таске не трогать — только сделать `setQuality`/`getQuality` безвредными заглушками, чтобы он компилировался; UI уберёт таск 06). На телефоне: материалы без clearcoat/sheen, текстуры K = 1, тени статичные (`shadowMap.autoUpdate=false`, `needsUpdate` после пересборки и дверцы), «вечерние» источники света днём `visible=false`, MSAA выключен, вместо него дешёвый FXAA в финальном проходе; живой вид рисуется в offscreen-цель `ratio × css` и холст при жесте не пересоздаётся; движение min(dpr, 1,5), покой min(dpr, 3) в бюджете 4 Мп. Регулятор снижает тени → текстуры → резкость (минимум 0,85 при dpr ≥ 2) и восстанавливает по времени. Пересборка по частям: смена ширины/цвета/позиции пересобирает только затронутую стену; фото техники обновляет только свою плитку. Шейдеры компилируются заранее за экраном загрузки. «Фото» на телефоне — сразу 4K-снимок (3840 px плитками) с полными материалами (временный класс `photo`), без трассировки; на компьютере как сейчас. Эскизы стилей — кэш по стиль+форма, не более 8 за раз, только после простоя.

## Критерии приёмки

- [ ] `pickTier()` даёт класс по памяти/ядрам/GPU/pointer; тесты на 4 класса; `localStorage` про качество не читается и не пишется
- [ ] Телефон: `MeshStandardMaterial` (без clearcoat/sheen/anisotropy) для фасадов/столешниц; K = 1; `antialias:false` + FXAA-проход; вечерние источники `visible=false` днём (проверка: `scene.traverse` — нет видимых источников с intensity 0)
- [ ] Тени: `autoUpdate=false`; `needsUpdate=true` после `setKitchen`, открытия дверцы, смены света; ручки и мелкие детали `castShadow=false`
- [ ] Холст: `renderer.setSize`/`setPixelRatio` не вызываются на жесте (только на resize и смене класса); масштаб — через offscreen-цель
- [ ] Регулятор: сначала тени (2048→1024→выкл), затем K, затем ratio ≥ 0,85 (dpr ≥ 2); восстановление по таймеру 3 с без быстрых-кадров-подряд; тесты
- [ ] Пересборка по стенам: `setKitchen` с изменением на одной стене пересобирает только её группу (счётчик пересобранных групп в тесте/консоли dev); фото техники → только `map` плитки
- [ ] `compileAsync` перед первым кадром; смена класса не переключает `castShadow` всей сцены
- [ ] `snapshot4k` на телефоне временно включает класс `photo` (полные материалы, тени 2048) и возвращает 3840 px; трассировка на телефоне не запускается (`startPhoto` → сразу снимок)
- [ ] Эскизы стилей: кэш, ≤ 8, после простоя 300 мс; на `phone-low` — без пересборки для эскизов (используется снимок общей кухни с подменой цвета, если пересборка дороже 200 мс — решить и записать в interfaces.md)
- [ ] tsc, vitest, build зелёные; на странице `/ru/kitchen` в размере телефона нет ошибок в консоли; коммит; сигнатуры в `interfaces.md`
