## Что должно заработать

Покупатель в «Отделка → Фасады» выбирает RAL (кодом или из палитры) или декор ЛДСП (по бренду или поиском), для всей кухни / низа / верха / острова; видит его в 3D; мастер получает код в Excel, PDF, смете; в WhatsApp уходит список цветов с кодами.

## Из брифа, дословно

> «Mijoz yoki usta RAL kodini yozadi (masalan, RAL 7016), fasad 3D'da shu rangga kiradi.»
> «Dekor 3D'da ko'rinadi va Excel raskroyga kodi bilan tushadi, shuning uchun usta listni xato buyurtma qilmaydi.»
> «Orol (ostrov) uchun uchinchi rang.»
> «mijoz 3D'da ko'rgan rang real buyurtmadagi rang bilan bir xil bo'ladi»

Истории 1–2, 4–12; Решения §2, §7.

## Критерии приёмки

- [ ] «Фасады»: к материалам (ламинат, акрил, эмаль, шпон, Fenix) добавлены «RAL» и «Декоры ЛДСП». RAL: поле «Код RAL» (принимает форматы `parseRal`; неизвестный — подпись «такого кода RAL нет», цвет не сбрасывается) + палитра по группам (первая цифра кода). Декоры: чипы брендов Egger / Kronospan / Lamarty, плитки «код + название»
- [ ] Поиск (одно поле, `findColors`): по коду/названию во всех видах; пусто — «Ничего не нашлось по «…»»; выбор из результата применяется как обычный цвет
- [ ] Под палитрой RAL и декоров: «Цвет на экране примерный — смотрите образец у продавца» (RU/KY)
- [ ] «Для чего»: «Вся кухня / Низ / Верх / Остров» — «Остров» только у кухни с островом; у острова «Как у низа» по умолчанию; `FinishLook.island` передаётся в 3D (см. отчёт таска 02 в interfaces.md); `CutLook.islandFacade` передаётся в раскрой
- [ ] Код цвета везде: подпись цвета в раскрое (`CutMaterial.label`) = «<код> <название>», если код есть → Excel «Распил»/«Фасады»/«Листы», карта раскроя, смета (строки листов и фасадов — с цветом и кодом); PDF мастеру «Отделка» — низ/верх/остров с кодами; `whatsappText` — строка «Фасады: …» (низ/верх/остров, с кодом, только если выбрано не «как в стиле»)
- [ ] Телефон 375×812 и 360: поиск, вкладки, плитки в 3 колонки, без горизонтальной прокрутки; RU/KY; фокус/клавиатура: поле кода RAL — `inputmode` подходящий, Enter применяет
- [ ] Тесты: `whatsappText` с RAL/декором/островом (RU/KY); Excel — код в «Цвет»; смета — строка с кодом; `kitchen-texts` (термины) зелёный; старые тесты зелёные
- [ ] Проверка в браузере (headless, `--disable-3d-apis` если тяжело): RU/KY, 1440 и 375 — ввод `7016` применяет RAL, поиск `H1145` находит декор, остров перекрашивается (снимок с 3D хотя бы один, если машина тянет), Excel содержит код
- [ ] `npx tsc --noEmit`, `npx vitest run`, `npm run build` зелёные
