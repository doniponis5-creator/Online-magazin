# Спецификация: пакет цвета — любой RAL, декоры ЛДСП с кодом, свой цвет острова

## Задача

Покупатель выбирает в 3D цвет фасадов, но в каталоге 52 цвета без кодов. Мастер потом переспрашивает «а это какой декор?», красит «примерно такой» эмалью, заказывает лист «похожий». Кухня, которую клиент видел, и кухня, которую сделали, расходятся по цвету.

## Решение

В «Отделка → Фасады» появляются два новых вида цвета: **RAL** (любой код из палитры RAL Classic — для крашеных фасадов, эмаль МДФ) и **Декоры ЛДСП** Egger, Kronospan, Lamarty с настоящим кодом. Цвет ищется по коду или названию. У острова — своя отделка. Код цвета/декора идёт везде, куда уходит кухня: в Excel для распила, PDF мастеру, смету, WhatsApp и ссылку.

## Решения по реализации

1. **Один резолвер цвета.** Новые виды цвета — это те же id фасада, которые понимает `frontColor(id)`: `ral-7016` (материал `enamel`, цвет из таблицы RAL) и `dec-<бренд>-<код>` (материал `laminate`, фактура из декора). Тогда ссылка, автосохранение, 3D, раскрой, смета принимают их без своих веток. Почему: у проекта уже одна точка разбора отделки; вторая — это расхождение 3D и раскроя.
2. **`FrontColor` += `code?: string`** (печатный код: «RAL 7016», «Egger H1145 ST10») и `brand?`. Всё, что печатает цвет (Excel, PDF, смета, WhatsApp), печатает `code + название`, если код есть.
3. **Таблица RAL** — RAL Classic целиком (≈215 кодов), экранный цвет по общепринятой таблице sRGB, название по-русски. **ASSUMPTION:** в KY показывается тот же код и русское название (названия RAL — имена цветов, переводить 215 строк не нужно).
4. **Декоры** — отдельный список: бренд, код, название RU/KY, цвет, фактура (`wood` / `concrete` / `stone` / нет). **ASSUMPTION:** стартовый набор — по 10–12 ходовых декоров Egger, Kronospan, Lamarty, код и название сверены с официальным каталогом бренда; правится в одном файле. Фото декоров не скачиваются (права производителя) — рисунок генерирует имеющийся генератор фактур.
5. **Остров** — новое поле `islandFacade` (как `upperFacade`: id или нет = как у низа), ключ ссылки `if`; в 3D у острова свой материал; в `SpecFront` / панелях острова — признак `island`, раскрой красит их цветом острова.
6. **Фактура камня** для декоров «камень» — если генератора нет в `catalogFront`, берётся `marble`/`speckle` из имеющихся фактур.
7. **Тексты** — только `texts.ts`, RU/KY; термины прежние.

## Вне рамок

| Требование | Почему не сейчас |
|---|---|
| Пакет света (LED, лампы, время суток) | владелец выбрал «1» — пакет цвета |
| Фото настоящих декоров | права производителя; фото образцов от владельца подкладываются потом |
| RAL для корпуса и столешницы | RAL — крашеный фасад; корпус ЛДСП не красится |
| NCS и другие палитры | в брифе — RAL |
