# 05 — Сервер: напоминания о корзине

**Требования:** G01, G01.1i
**Blocked by:** 01
**Зона:** `integrations/sbonus-server/shop/`
**Волна:** 2
**Status:** ready

## Что должно заработать

Сервер хранит снимок корзины вошедшего покупателя приложения и его согласие на напоминания.
Раз в 30 минут задача проверяет, кому пора напомнить, и шлёт через существующий `send()` —
на iPhone и на Android. Напоминает только днём (10:00–20:00 по Бишкеку), только с согласия,
только если корзина не пуста и с её изменения не было заказа. Любое изменение корзины начинает
расписание заново. Удаление учётной записи стирает и эту строку.

## Из брифа, дословно

> «korzinasida tavar bor bolsa yu ilovadan chiqib ketgan bolsaham eslatib tursin nechkundaham bir»

## Разделы спецификации

«Решения по реализации» §6; `interfaces.md` — «Напоминание о корзине» и «Из таска 01».

## Расписание

**СХЕМА:** см. строку G01 в `manifest.md` — там ответ владельца. Держи расписание одной константой в
`shop_cart_rules.py` (например `SCHEDULE_DAYS = (1, 3, 7)` — пауза после изменения корзины, потом после
каждого напоминания; `REPEAT_EVERY = None` или число дней для «повторять до покупки»), чтобы смена схемы
была правкой одной строки.

## Критерии приёмки

- [ ] Миграция `010_shop_cart_reminders_migration.sql` — таблица по `interfaces.md`, идемпотентна; `deploy_shop.sh` знает о ней
- [ ] `/webhook/site/push-cart` и `/webhook/site/cart-consent` (подпись сайта — как у соседних `/webhook/site/*`);
      изменение состава сбрасывает `sent` и `changed_at`; согласие читается и пишется; телефон — только из тела,
      подписанного сайтом
- [ ] `shop_cart_rules.py` без импортов приложения: `due(row, now) -> bool` (согласие, count>0, тихие часы в
      Бишкеке, расписание, лимит), `reminder_text(items, count) -> (title, body)` — «Товары ждут в корзине» /
      «{первый}{ и ещё N} — оформите заказ, когда будет удобно.»; без выдуманной срочности
- [ ] `shop_cart_remind.py` — `python3 -m app.shop.shop_cart_remind`: одна проверка и выход; пропускает тех, у кого
      после `changed_at` есть заказ этим номером; шлёт через `shop_push.send(..., data={"type": "cart"})`;
      увеличивает `sent`/`last_sent_at` только при доставке хотя бы на один телефон; журнал — без номеров целиком
- [ ] Заказ этим номером (создание заказа сайтом) обнуляет корзину на сервере; удаление учётной записи
      (`/webhook/site/account-delete`) стирает строку
- [ ] `deploy_shop.sh` ставит в `crontab` хоста строку раз в 30 минут с `flock` (по образцу существующей строки
      autosave: `docker exec -e PYTHONPATH=/app sbonus_api python3 -m app.shop.shop_cart_remind`), не дублирует при
      повторном запуске, пишет журнал в `/root/shop_cart_remind.log`
- [ ] Unit-тесты `shop_cart_rules` (расписание по шагам, тихие часы на границах 10:00/20:00 по Бишкеку, пустая
      корзина, нет согласия, лимит, текст с 1 и с несколькими товарами) — `uv run python -m unittest …` зелёные;
      тесты таска 01 по-прежнему зелёные; `py_compile` по изменённым файлам
