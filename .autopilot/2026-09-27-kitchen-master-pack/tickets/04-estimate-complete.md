## Что должно заработать

Смета клиенту включает всю фурнитуру из спецификации, а не часть: мастер не должен занизить цену кухни, потому что строки просто не было. Каждое напечатанное число в смете сходится: кол-во × цена = сумма.

## Критерии приёмки

- [ ] `MasterPrices` += `leg`, `hanger`, `push` (за шт), `gola`, `plinth` (за м); строки сметы из `hardware(spec)` (`legs`, `hangers`, `push`, `gola`, `plinth`) — есть в кол-ве > 0 → строка; нет цены — «цена не указана», в итог не входит (как все)
- [ ] Лист ЛДСП: две цены — «белый» (`ldsp`, как было) и «цветной / декор» (`ldspDecor`). Группа листов корпуса по умолчанию (`lam-white`) и любая другая белая группа того же материала — по белой цене; группа в цвет фасада/верха — по цветной. Нет цветной цены — строка «цена не указана» (НЕ подставлять белую — цены знает только мастер). Старая запись `kp-master` без новых полей читается без потерь
- [ ] Форма «Мои цены и данные»: новые поля RU/KY; «Работа» подписана так, чтобы было ясно, что за метр **столешницы** (так она и считается); размер листа: если введена одна сторона без другой — видимая подсказка у поля, а не молчаливый пропуск
- [ ] Форма: при открытии фокус в окне, Tab не уходит за окно, Esc и «Закрыть» закрывают, фокус возвращается на кнопку, которая открыла
- [ ] Строки сметы (название, кол-во с единицей, цена, сумма) и строки техники собираются чистой функцией вне `KitchenPlanner.tsx` (например, `estimateLines(...)` в `master.ts` с `t` параметром — как `cutWorkbook`); экран и PDF берут одно и то же
- [ ] Тест: для угловой и П-образной кухни с полным набором цен, RU и KY — у каждой строки напечатанное кол-во × цена = напечатанная сумма (с учётом формата «4,78»); сумма строк = «Сумма по строкам»; техника: сумма строк = «Итого техника»
- [ ] Наценка в подписи — точно как введена (12,25% → «12,25%»), не округлённая до десятых
- [ ] Название строки направляющих — свой ключ в `texts.ts`, без `split(',')`
- [ ] Проверка в браузере: смета PDF RU и KY (1440 и 375) — кол-во «4,78 м», суммы сходятся, новые строки видны; снимки страниц — в scratchpad
- [ ] `npx tsc --noEmit`, `npx vitest run`, `npm run build` зелёные
