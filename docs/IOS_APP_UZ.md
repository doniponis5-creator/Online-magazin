### Нега «фақат иконка» ишламайди

Apple нинг 4.2-қоидаси: «қайта ўралган сайт» рад этилади. Текширувчи иловани очади, ичида веб-саҳифадан бошқа ҳеч нарса кўрмайди — ва қайтаради. Бу таҳмин эмас, бу уларнинг ёзилган қоидаси.

### Нега тўлиқ native ҳозир тўғри эмас

iOS учун алоҳида интерфейс дегани — Android учун ҳам алоҳида. Уччала жойда (сайт, iPhone, Android) ҳар бир ўзгаришни уч марта қилиш керак бўлади. Бир кишилик дўкон учун бу оғир ва секин.

### Тавсия: B йўли

**Профессионал кўриниш технологиядан эмас, тезлик ва ҳис-туйғудан келади.** Харидор «бу Capacitor ми, Swift ми» деб сўрамайди. У шуни сезади:

- илова **бир сонияда** очиладими
- браузер белгилари (манзил қатори, «орқага» тугмаси) кўринмайдими
- интернет йўқ жойда ҳам SBonus картаси очиладими
- хабарлар келадими

Буларнинг ҳаммаси B йўлида бор. Яхши қилинган B — ёмон қилинган C дан профессионалроқ кўринади.

## 8. Ҳозирги ҳолат

Янгиланди: 18.09.2026, MacBook да. Шоха (branch) `feature/ios-app`.

### 1–2-қадам битди: iOS лойиҳаси, иконка, очилиш экрани

- Capacitor 8.5.2, `ios/` папкаси. Илова номи **«S Маркет»** (дўкон номи — Smart Centr,
  онлайн дўкон — S Маркет). Apple учун белгиси (Bundle ID) `kg.smarket.app`.
- Ичида `https://smarket.kg` очилади. Манзил қатори ҳам, «орқага» тугмаси ҳам йўқ.
- Иконка ва очилиш экрани сайт рангларида: тўқ кўк фон `#263244`, лимон сариқ «S».
  Қайта ясаш: `node scripts/make-ios-icon.mjs`.
- Интернет йўқ бўлса — `ios-web/index.html` саҳифаси (рус ва қирғиз тилида).
- Энг эски iPhone: iOS 16.

### 3-қадам битди: SBonus бонус картаси, интернетсиз

Бу — иловадаги биринчи чинакам «телефон имконияти». Apple 4.2-қоидаси учун шарт.

- Код: `ios/App/App/BonusCard.swift` (Swift, илованинг ўз коди).
- Мижоз сайтга кирганда карта телефоннинг **Keychain** ига ёзилади
  (Keychain — телефоннинг ҳимояланган хотираси, паролллар шу ерда туради).
- QR ни телефоннинг ўзи чизади (CoreImage). Сервер ҳам, интернет ҳам керак эмас.
- Кассада экран ёрқинлиги ўзи максимумга чиқади, карта ёпилганда ортга қайтади.
- Кирадиган жойлар: «Кабинет» саҳифасидаги **«Бонусная карта»** тугмаси ва
  интернет йўқ саҳифасидаги ўша тугма.
- Чиқиш (выход) қилинса — карта телефондан ўчирилади.

Сайт томони: `src/lib/native/bonusCard.ts`, `src/components/AccountView.tsx`.
Сервер томони: `integrations/sbonus-server/shop/shop_customers.py` энди профилда
`qrCode` (мижознинг SBonus даги коди, `SB-XXXXXXXXXX`) қайтаради.

Симуляторда синалди (iPhone 17 Pro, iOS 26.4): кириш → карта сақланди → сервер
ўчирилди → илова қайта очилди → карта QR билан очилди.

**⚠ Текшириш керак:** кассадаги сканер айнан шу `SB-XXXXXXXXXX` кодни ўқийдими?
Мен буни била олмадим — SBonus нинг касса дастури бу репозиторийда йўқ. Агар касса
бошқа нарсани кутса (масалан телефон рақамини), фақат биттагина жойни ўзгартирамиз:
серверда `qrCode` га нима қўйилса, QR да ўша чиқади.

### 5-қадам битди: Face ID билан кириш

- Код: `ios/App/App/AppLock.swift` (илованинг ўз коди).
- Мижоз код билан кирганда, сайт унга калит беради. Илова калитни Keychain га
  **қулф остида** қўяди: калитни олиш учун юз (ёки бармоқ изи, ёки телефон коди) керак.
- Кириш муддати тугаса — «Кабинет» да **«Войти по Face ID»** тугмаси чиқади.
  Юзни кўрсатса — Telegram дан код кутмасдан ичкарига киради.
- «Выйти» босилса, калит телефондан ўчирилади.
- Калит бошқа «имзо» билан имзоланган: уни cookie ўрнига қўйиб бўлмайди ва аксинча.

Сайт томони: `src/lib/native/appLock.ts`, `src/app/api/customer/native-key/route.ts`,
`src/lib/customer/session.ts` (`encodeNativeKey` / `decodeNativeKey`).

Синалди: калит берилади, калит билан кириш ишлайди, сохта калит рад этилади (401),
симуляторда тугма чиқди ва кириш амалга ошди.

**⚠ Ҳақиқий iPhone да текшириш керак:** симуляторда Face ID сўрови ўзи ўтиб кетади.
Ҳақиқий телефонда юз сўралишини кўз билан кўриш керак.

### 4-қадам: push хабарлар — илова тайёр, Apple калити кутилмоқда

**Илова томони битди ва синалди.** Симуляторда: рухсат сўралди, Apple телефон
«манзили» (token) ни берди, у сайтга етиб борди, синов хабари экранда чиқди —
иконкамиз, «S Маркет» номи ва «1» белгиси билан.

- Илова: `@capacitor/push-notifications`, `ios/App/App/AppDelegate.swift`,
  `ios/App/App/App.entitlements` (`aps-environment`).
- Сайт: `src/lib/native/push.ts`, `src/app/api/push/device/route.ts`.
  «Кабинет» да **«🔔 Уведомления о заказах»** тугмаси — рухсатни ўша ерда сўраймиз.
- Сервер: `integrations/sbonus-server/shop/shop_push.py`,
  `005_shop_push_migration.sql` (жадвал `shop_push_devices`),
  `shop_admin.py` даги `/webhook/site/push-device`.
- Қачон юборилади: **буюртма тўланганда** ва **1С буюртмани расмийлаштирганда**
  («Заказ готов», бонус ҳам ёзилади).

**Сиздан керак — Apple калити** (developer.apple.com → Keys → «+» →
Apple Push Notifications service):
1. `.p8` файлни юклаб олинг — **у фақат бир марта юкланади**, сақлаб қўйинг.
2. **Key ID** (10 белги) ва **Team ID** (10 белги) ни ёзиб олинг.
3. Компьютерингизда ишга туширинг:
   `powershell -ExecutionPolicy Bypass -File scripts\setup-apns.ps1`
   Скрипт файлни ўзи ўқийди, экранга ҳеч нима чиқармайди.
4. Кейин серверни янгилаймиз: `deploy_shop.sh`.

Калит йўқ бўлса — сервер ҳеч нима юбормайди ва ҳеч нима бузилмайди.

**Сервер ўрнатилди 18.09.2026:** `deploy_shop.sh` ўтди, жадвал `shop_push_devices`
яратилди, `h2` кутубхонаси (Apple фақат HTTP/2 қабул қилади) `requirements.txt` га
қўшилди. Apple калити ёзилган: Key ID `8CH49X79SQ`, Team ID `434V33P6X2`,
ҳозирча sandbox (илова App Store да эмас). Сервер «ключ Apple задан: True» дейди.

Сайт ҳам янгиланди (`update_site.sh`). Текширилди: `/api/push/device` телефон
манзилини қабул қилиб, базага ёзди; `/api/customer/native-key` кирмаган одамни 401
билан қайтарди.

**⚠ Ҳақиқий телефонда ҳали синалмаган:** симуляторга Apple орқали хабар юбориб
бўлмайди. Ҳақиқий iPhone га илова ўрнатилганда текширамиз.

### Mac да йиғиш

Диққат: `CODE_SIGN_IDENTITY="-"` шарт. Имзосиз йиғилса, Keychain ишламайди
ва карта сақланмайди (хато коди −34018).

```
cd ios/App && xcodebuild -scheme App -configuration Debug -sdk iphonesimulator \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' \
  -derivedDataPath build CODE_SIGN_IDENTITY="-" CODE_SIGNING_REQUIRED=NO \
  CODE_SIGNING_ALLOWED=YES
```

Локал сайтда синаш учун `capacitor.config.ts` даги `url` ни вақтинча
`http://localhost:3000` га ўзгартириб, `npx cap sync ios` қилинади, кейин орқага
қайтарилади.

Сайт тайёр ва ишлаяпти: `smarket.kg`, каталог 1С дан келади, буюртма O!Деньги орқали тўланади, SBonus бонуслари уланган, кириш Telegram коди билан.
