## 1. Асосий савол: ҳақиқий илова ми, «сайт қобиғи» ми

Учта йўл бор. Иккитаси реал, биттаси хато.

| Йўл | Нима бу | Иш ҳажми | Apple қабул қиладими |
|---|---|---|---|
| **A. Фақат иконка** | Сайтни ўзгартирмасдан қобиққа солиш | 1–2 кун | **Йўқ** — рад этади |
| **B. Қобиқ + чинакам мобиль имкониятлар** | Сайт ичкарида, лекин push, QR, Face ID телефоннинг ўзиники | 3–5 ҳафта | **Ҳа** |
| **C. Тўлиқ native (SwiftUI)** | iOS учун алоҳида интерфейс нолдан | 3–6 ой | Ҳа |

### Нега «фақат иконка» ишламайди

Apple нинг 4.2-қоидаси: «қайта ўралган сайт» рад этилади. Текширувчи иловани очади, ичида веб-саҳифадан бошқа ҳеч нарса кўрмайди — ва қайтаради. Бу таҳмин эмас, бу уларнинг ёзилган қоидаси.

### Нега тўлиқ native ҳозир тўғри эмас

iOS учун алоҳида интерфейс дегани — Android учун ҳам алоҳида. Уччала жойда (сайт, iPhone, Android) ҳар бир ўзгаришни уч марта қилиш керак бўлади. Бир кишилик дўкон учун бу оғир ва секин.

### Тавсия: B йўли

**Профессионал кўриниш технологиядан эмас, тезлик ва ҳис-туйғудан келади.** Харидор «бу Capacitor ми, Swift ми» деб сўрамайди. У шуни сезади:

- илова **бир сонияда** очиладими
- браузер белгилари (манзил қатори, «орқага» тугмаси) кўринмайдими
- интернет йўқ жойда ҳам SBonus картаси очиладими
- хабарлар келадими

Буларнинг ҳаммаси B йўлида бор. Яхши қилинган B — ёмон қилинган C дан профессионалроқ кўринади.

## 2. Apple рад этмаслиги учун иловада нима бўлиши шарт

Бу рўйхат — қобиқни чинакам иловага айлантирадиган нарсалар. Ҳар бири телефоннинг ўз имконияти, сайтда бўлиши мумкин эмас.

| Имконият | Нега керак | Муҳимлиги |
|---|---|---|
| **SBonus QR картаси интернетсиз** | Кассада телефонни кўрсатади, интернет бўлмаса ҳам ишлайди | Энг муҳими |
| **Push хабарлар** | «Буюртмангиз тайёр», «чегирма» — сайт буни қила олмайди | Жуда муҳим |
| **Face ID / бармоқ изи билан кириш** | Код кутиш йўқолади | Муҳим |
| **Каталог интернетсиз очилиши** | Метро, лифт, заиф тармоқда ишлайди | Муҳим |
| **Камера билан QR ўқиш** | Товарни сканерлаб топиш | Яхши бўларди |
| **Телефон контактига улашиш** | Товарни дўстга юбориш | Яхши бўларди |

Биринчи тўрттаси **шарт**. Улар бўлмаса топширмаймиз — вақт беҳуда кетади.

## 4. Mac да биринчи қадамлар

Терминални очинг (Spotlight → «Terminal»).

**1-қадам. Лойиҳани олиш:**

```
git clone https://github.com/doniponis5-creator/Online-magazin.git
```

**2-қадам. Папкага кириш ва кутубхоналарни ўрнатиш:**

```
cd Online-magazin && npm install
```

**3-қадам.** Claude Desktop ни очинг → `Online-magazin` папкасини танланг → ёзинг:

> iOS иловасини бошлаймиз

Ундан кейин ҳамма техник ишни Claude қилади, сиз тасдиқлайсиз.

## 7. Android ҳақида

iOS битгач, Android **тезроқ** бўлади: бир хил Capacitor лойиҳасидан иккинчи илова чиқади. Google Play текшируви ҳам Apple никидан енгилроқ. Google Play аккаунти бор — 25 USD, бир марта.

Иккаласини бир вақтда очиш режаси шунга мос: аввал iOS (қийинроғи), кейин Android.
