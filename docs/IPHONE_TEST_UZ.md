## Аввал биладиган нарса

Симуляторда **иккита** нарсани текшириб бўлмайди, шунинг учун ҳам бу қадам керак:

- **Face ID** — симуляторда сўров ўзи ўтиб кетади, юз сўралмайди.
- **Push хабарлар** — Apple симуляторга хабар юбормайди.

Қолгани симуляторда аллақачон ишлади.

## Телефонни тайёрлаш

**Бу аллақачон қилинган** (19.09.2026): iPhone 17 Pro Max MacBook га боғланган,
дастурчи режими ёқилган, Apple ID Xcode да турибди. Боғланиш **Wi-Fi орқали**,
шунинг учун кабель ҳар сафар керак эмас — телефон ва MacBook битта Wi-Fi да
бўлса бўлгани.

Бошқа телефонга қўйиш керак бўлса, ўша учун бир марта:

1. Кабель билан уланг, телефон қулфдан чиққан бўлсин. «Бу компьютерга
   ишонасизми?» деса — **«Ишониш»**.
2. Настройки → Конфиденциальность и безопасность → **Режим разработчика** →
   ёқинг. Телефон қайта юкланади.
3. Xcode → Settings → Accounts → «+» → Apple ID билан киринг.

## Иловани телефонга қўйиш

Терминалда:

```bash
bash scripts/install-on-iphone.sh
```

Скрипт телефонни ўзи топади (Xcode дан сўрайди, шунинг учун Wi-Fi боғланишни
ҳам кўради), иловани ҳақиқий имзо билан йиғади ва ўрнатади.

**19.09.2026 да ишлади:** имзо «Apple Development: Abduganiev Donierbek
Makhammadzhonovich», илова `kg.smarket.app` телефонга ўрнатилди.

Скрипт ишлаганда `Failed to load provisioning paramter list ... No provider was
found` деган қатор чиқади. **Бу хато эмас**, Apple нинг ўз огоҳлантириши; ундан
кейин `App installed` ёзилса — ҳаммаси жойида.

Биринчи ишга туширишда телефон «Ишонилмаган дастурчи» дейиши мумкин. У ҳолда:
Настройки → Основные → **VPN и управление устройством** → аккаунтингизни
танланг → **«Доверять»**.

## Текшириладиган рўйхат

Ҳар бирини қилиб, натижани ёзиб қўйинг. Ишламаса — нима бўлганини айтинг,
тузатамиз.

### 1. Илова очилиши

- [ ] Иконка тўғри кўринадими (тўқ кўк фон, лимон сариқ «S»)
- [ ] Очилиш экрани кўринадими
- [ ] Сайт **бир-икки сонияда** очиладими
- [ ] Манзил қатори ва «орқага» тугмаси кўринмайдими

### 2. Кириш

- [ ] Телефон рақами киритилди, код **Telegram** га келдими
- [ ] Telegram да код келмаса — **WhatsApp** га келдими
- [ ] Код билан кирилдими

### 3. Бонус картаси

- [ ] «Кабинет» да **«Бонусная карта»** тугмаси борми
- [ ] Босилганда карта очиладими, QR кўринадими
- [ ] Карта очилганда **экран ёрқинлиги ўзи кўтариладими**
- [ ] Карта ёпилганда ёрқинлик ортга қайтадими

### 4. ⚠ Кассадаги сканер — энг муҳим текширув

Бу саволга жавобни фақат сиз бера оласиз.

- [ ] Телефондаги QR ни **кассадаги сканерда** ўқитиб кўринг
- [ ] Касса мижозни топдими?

**Топмаса паника йўқ.** QR да ҳозир мижознинг SBonus даги коди
(`SB-XXXXXXXXXX`) турибди. Касса бошқа нарсани кутаётган бўлса (масалан
телефон рақамини) — битта жойни ўзгартирамиз, иловани қайта ёзиш керак эмас.
Менга шуни айтинг: **касса нимани кутади**.

### 5. Face ID

«Кабинет» да **«Быстрый вход»** деган блок бор — Face ID шу ерда бошқарилади.

- [ ] Блокда **«Face ID · Включён»** деб турадими
- [ ] **«Проверить»** тугмасини босинг — телефон **юзни сўрадими**
      (симуляторда буниси кўринмайди, шунинг учун айнан шу текширув муҳим)
- [ ] Юзни кўрсатгач **«✓ Сработало»** деб ёзилдими
- [ ] **«Выключить»** босинг — «Выключен» бўлдими
- [ ] **«Включить»** босинг — яна «Включён» бўлдими

Эслатма: «Войти по Face ID» тугмаси кириш саҳифасида бор, лекин у фақат
кириш муддати тугагандан кейин кўринади. Кутманг — «Проверить» шу иш учун.

### 6. Push хабарлар

- [ ] «Кабинет» да **«🔔 Уведомления о заказах»** тугмаси борми
- [ ] Босилганда iPhone рухсат сўрадими, «Разрешить» босилдими
- [ ] Синов буюртмаси беринг ва тўланг
- [ ] **«Заказ оплачен»** хабари телефонга келдими
- [ ] 1С да буюртма расмийлаштирилгач, **«Заказ готов»** келдими
- [ ] Хабарда иконкамиз ва **«S Маркет»** номи кўринадими

### 7. Иловани ёпиб, қайта очиш

- [ ] Кириш сақланиб қолдими (қайтадан код сўралмадими)

### 8. Каталог интернетсиз

**Аввал сайт янгиланган бўлиши керак** — юқоридаги огоҳлантиришга қаранг.

- [ ] Интернет бор пайтда иловани очинг, каталогни кўринг, бир-икки дақиқа
      кутинг (илова каталог суратини шу пайтда олади)
- [ ] Телефонда **«Авиарежим»** ни ёқинг
- [ ] Иловани ёпиб, қайта очинг
- [ ] **«Нет связи»** саҳифаси чиқдими
- [ ] Унда **«Каталог · Каталог»** тугмаси борми
- [ ] Босилганда товарлар рўйхати очиладими
- [ ] Излаш ишлайдими (масалан «LG» деб ёзинг)
- [ ] Бўлимлар ишлайдими («Холодильники» ни босинг)
- [ ] **«Бонусная карта»** тугмаси ҳам шу ерда ишлайдими
- [ ] «Закрыть» орқага қайтарадими
- [ ] Авиарежимни ўчиринг, «Повторить» — сайт очиладими

Эслатма: рўйхатда ҳозир «Цена по запросу» ва бир хил белги кўринади. Бу хато
эмас: 1С дан келаётган каталогда ҳозир на нарх, на фото бор
(`docs/TODO_NEXT.md`, 3-вазифа). 1С дан нарх келса, ўша ернинг ўзида чиқади.
