# Онлайн-консультант в Instagram

Робот отвечает в Direct аккаунта **smartcentrr** так же, как в WhatsApp:
ждёт сотрудника 5 минут (та же настройка «WhatsApp: сколько минут ждать сотрудника» в 1С),
и только если никто не ответил — отвечает сам: цена, фото, ссылка на товар.

Как это устроено:

```
Покупатель пишет в Direct
   → Meta присылает сообщение на сервер SBonus (webhook — адрес, куда Meta сама шлёт сообщения)
   → сервер ждёт сотрудника 5 минут
   → спрашивает консультанта на сайте (/api/channel/instagram)
   → отправляет ответ в Instagram
```

## Чем Instagram отличается от WhatsApp

- **Номера телефона нет.** Робот не назовёт бонусы и заказы. Для заказа или звонка он спросит номер сам.
- **Окно 24 часа.** Meta разрешает писать покупателю только 24 часа после его последнего сообщения.
  Поэтому «ещё актуально?» робот шлёт только внутри этого окна, а «напишу после зарплаты» через 5 дней — не шлёт.
- **Сотрудник отвечает из приложения Instagram как обычно.** Робот видит это и молчит в этом чате 12 часов.
- **Реклама.** Если покупатель пришёл из рекламы, робот видит название объявления и отвечает про этот товар.

## Что сделать владельцу

### Шаг 1. Аккаунт Instagram (в телефоне)

1. Аккаунт **smartcentrr** должен быть профессиональным (бизнес): «Настройки» → «Тип аккаунта и инструменты».
2. «Настройки» → «Сообщения и ответы на истории» → «Инструменты для сообщений» (Connected tools) →
   включить **«Разрешить доступ к сообщениям»**. Без этого Meta не отдаёт сообщения программе.

### Шаг 2. Приложение в кабинете Meta

1. Откройте https://developers.facebook.com → «Мои приложения» → «Создать приложение».
2. Сценарий: **«Управление сообщениями и контентом в Instagram»** (Instagram API).
3. В приложении: «Instagram» → **«Настройка API со входом через Instagram»** (API setup with Instagram login).
4. «Добавить аккаунт» → войдите в **smartcentrr** → нажмите **«Создать маркер»** (Generate token).
   Это `IG_ACCESS_TOKEN`. Сохраните его в заметках телефона — **не присылайте в чат**.
5. На той же странице — **«Секрет приложения Instagram»** (Instagram app secret). Это `IG_APP_SECRET`.

### Шаг 3. Установка на сервер (один раз)

Сначала новый код сервера и сайта. Команды — в PowerShell, из папки проекта.

Сервер SBonus:

```
ssh root@145.223.100.16 "rm -rf /tmp/sb_shop"
scp -r integrations/sbonus-server/shop root@145.223.100.16:/tmp/sb_shop
ssh root@145.223.100.16 "bash /tmp/sb_shop/deploy_shop.sh"
```

Сайт:

```
powershell -ExecutionPolicy Bypass -File deploy\site\pack.ps1
scp smartcentr-site.tar.gz root@145.223.100.16:/tmp/
scp deploy/site/update_site.sh root@145.223.100.16:/tmp/
ssh root@145.223.100.16 "bash /tmp/update_site.sh"
```

Пока ключей нет, робот Instagram ничего не делает — WhatsApp и сайт работают как раньше.

### Шаг 4. Ключи на сервер

Откройте файл настроек сервера:

```
ssh -t root@145.223.100.16 "nano /opt/sbonus/.env.production"
```

В конец файла допишите две строки (вместо точек — ваши значения из шага 2):

```
IG_ACCESS_TOKEN=...
IG_APP_SECRET=...
```

Сохранить: `Ctrl+O`, `Enter`, выйти: `Ctrl+X`. Потом перезапустите сервер, чтобы он прочитал ключи:

```
ssh root@145.223.100.16 "cd /opt/sbonus && docker compose -f docker-compose.prod.yml up -d --no-deps --force-recreate api"
```

### Шаг 5. Подключить webhook в кабинете Meta

1. Узнайте слово для проверки (его создал установщик):

   ```
   ssh root@145.223.100.16 "grep IG_VERIFY_TOKEN /opt/sbonus/.env.production"
   ```

2. В приложении Meta: «Instagram» → «Настройка API со входом через Instagram» → **«Настроить webhooks»**:
   - Callback URL: `https://api.smartcentr.store/api/v1/webhook/instagram`
   - Verify token: слово из пункта 1 (только то, что после `=`).
   - «Проверить и сохранить».
3. Подпишитесь на поле **`messages`**.
4. В строке аккаунта **smartcentrr** включите переключатель **«Подписка на webhook»**.

### Шаг 6. Проверка

1. Пока приложение в режиме разработки, Meta шлёт сообщения только от тех, кто добавлен в приложение.
   Добавьте свой личный Instagram: «Роли приложения» → «Тестировщики Instagram», и примите приглашение
   в своём Instagram («Настройки» → «Приложения и сайты» → «Приглашения тестировщика»).
2. С личного аккаунта напишите **smartcentrr**: «Холодильник барбы?». Через 5–6 минут придёт ответ.
3. Журнал робота на сервере:

   ```
   ssh root@145.223.100.16 "tail -20 /var/log/sbonus-ig-bot.log"
   ```

4. Ответа нет — проверьте, доходят ли сообщения от Meta:

   ```
   ssh root@145.223.100.16 "docker logs sbonus_api --since 30m 2>&1 | grep -i 'ig webhook'"
   ```

   Если там «подпись не сошлась», значит, Meta подписывает сообщения другим секретом — основным
   секретом приложения («Настройки приложения» → «Основное» → «Секрет приложения»). Допишите его
   через запятую: `IG_APP_SECRET=секрет_instagram,секрет_приложения` — и перезапустите сервер (шаг 4).
   Точно не знаю, каким из двух секретов подписывает Meta, поэтому робот принимает оба.

### Шаг 7. Для всех покупателей

Чтобы робот отвечал всем, а не только тестировщикам, Meta проверяет приложение вручную (App Review)
и просит подтвердить бизнес. Сколько это длится — не уверен: бывает от нескольких дней до нескольких недель.
Что Meta попросит: короткое видео, как работает робот, и описание, зачем нужен доступ к сообщениям.

## Комментарии под постами (04.10.2026)

Робот отвечает и на комментарии — без Gemini, шаблоном (комментарий видят все, ошибку модели тоже):

| Комментарий | Что делает робот |
|---|---|
| «Канча?», «Цена», «+», «Ошко барабы?» | под комментарием «Директке жаздык 📩», в Direct — товар из подписи поста, цена и «Кайсы шаардан болосуз?». Товар по подписи не узнал — в Direct «Какой товар заинтересовал?», чужую цену не называет. Дальше разговор в Direct ведёт обычный робот |
| Жалоба («алдамчылар», «синди») | под комментарием «Кечиресиз! Директке жаздык», в Direct — «что случилось?», владельцу «🚨 ЖАЛОБА» в WhatsApp |
| Спам (чужая реклама, ставки, мат) | скрывает |
| «🔥», «супер», отметка друга | ничего |

Сортирует Jev (`src/lib/assistant/comments.ts`), выполняет сервер (`shop_ig_bot._handle_comments`). Одному человеку —
не больше трёх ответов в день, комментарии старше суток — без ответа. Выключается той же галочкой «Instagram-консультант».

**Подключить в кабинете Meta:** приложение → «Instagram» → «Настройка API со входом через Instagram» → шаг 3
«Настройте Webhooks» → в списке полей включить **`comments`** (рядом с `messages`). Разрешение
`instagram_business_manage_comments` уже стоит в шаге 1. Если в журнале `/var/log/sbonus-ig-bot.log` будет
«Instagram 403 … permission» — сгенерируйте новый ключ (шаг 2, пункт 4) и замените `IG_ACCESS_TOKEN` (шаг 4).

## Посты и истории «Скидка» / «Новинка» из 1С (04.10.2026)

В 1С: «Онлайн магазин» → «Панель сайта» → вкладка «Уведомления» → выберите товар и шаблон →
справа вкладка **«Пост в Instagram»** → «Куда»: **«Пост в ленту»** или **«История»**. Там картинка
и текст поста (его можно править; у истории текста нет — всё на картинке) →
**«Опубликовать в Instagram»** → «Да». Через 10–30 секунд пост в ленте; строка «Instagram» появится
в «Последних рассылках» внизу, двойной щелчок по ней открывает пост.

- Картинку рисует сайт в оформлении smarket.kg (DESIGN.md): фото товара, название, цена, «Скидка −N%»
  или «Новинка», «В наличии», телефон. Размер 1080 × 1350.
- Текст — по-русски и по-кыргызски, цена только из 1С. В нём полное название и цена — по ним робот
  комментариев узнаёт товар поста и отвечает на «Канча?» правильной ценой.
- Пост выходит только по кнопке. Без фото, без цены или без остатка — нельзя. Не больше 10 постов в день,
  один товар с одним шаблоном — раз в сутки. Не вышло — день не занимает, можно нажать ещё раз.
- Удалить пост можно только в самом Instagram.
- История — 1080 × 1920, висит 24 часа. Ссылку-стикер Instagram через программу не даёт, поэтому внизу
  лимонная плашка «Жооп жазыңыз — шилтеме жиберебиз». Короткий ответ на историю («Канча?», «+») — робот сразу,
  без Gemini, шлёт фото, цену и ссылку на товар на smarket.kg; длинный вопрос — отвечает как обычно.
- Каждая история (и кнопкой, и авто) уходит ещё и **статусом WhatsApp** магазина — там ссылка в подписи
  нажимается. Статус видят те, кто сохранил номер магазина. Green API помечает статусы «бета»: не вышел —
  в сообщении владельцу «Статус WhatsApp не вышел» и причина.
- **Авто-истории** — галочка «Авто-история в Instagram» в «Настройки сайта» (по умолчанию выключена):
  4 истории в день по меткам товара в 1С — 10:00 «Товар дня», 13:00 «Хит», 16:00 «Новинка»,
  19:00 «Специально для вас» (нет — «Скидка»). Нет товара с меткой — слот пропускается; один товар —
  не больше раза в день, с той же меткой — раз в три дня («Товар дня» — каждый день). Сервер лежал —
  слот ещё выйдет в течение двух часов. Что вышло — владельцу в WhatsApp.
  Посты в ленту робот сам не выпускает никогда.

**Один раз в кабинете Meta:** право `instagram_business_content_publish` должно быть включено, и после
этого нужен **новый ключ**: «Instagram» → «Настройка API со входом через Instagram» → «Создать маркер»
(шаг 2, пункт 4) → заменить `IG_ACCESS_TOKEN` (шаг 4). Старый ключ выдан без этого права — с ним
в «Последних рассылках» будет «не опубликован: Instagram не дал права публиковать».

Как устроено: 1С → `/promo/ig-preview`, `/promo/ig-post`, `/promo/ig-history` (`shop_admin.py`) →
`shop_ig_post.py` → сайт рисует картинку (`/api/instagram/post-image`, `src/lib/instagram/postImage.tsx`) →
сервер отдаёт её Meta по адресу `https://api.smartcentr.store/api/v1/shop/photos/ig/<v>.jpg` (с smarket.kg
Meta не заберёт: Cloudflare) → Instagram API: контейнер → `media_publish`.

## Готовые вопросы в Direct и карусель «Скидки недели» (04.10.2026)

- **Готовые вопросы** (ice breakers): кто впервые открывает Direct магазина, видит кнопки «Баасы канча?»,
  «Дарегиңиз кайда?», «Жеткирүү барбы?», «Насыяга алсам болобу?» (в русском Instagram — по-русски).
  Нажал — робот отвечает как на обычное сообщение. Ставит их сам робот (`shop_ig_bot._ensure_ice_breakers`,
  список — `shop_ig_rules.ICE_BREAKERS`). **В кабинете Meta** в Webhooks нужно включить поле
  **`messaging_postbacks`** — иначе нажатие до робота не дойдёт.
- **Карусель «Скидки недели»**: 1С → «Уведомления» → «Пост в Instagram» → «Куда»: «Скидки недели (карусель)» →
  «Опубликовать». Товар выбирать не нужно: обложка «Аптанын арзандатуулары · Скидки недели» и до 9 карточек
  товаров со скидкой и фото (самые большие скидки первыми), в подписи — каждый товар с ценой. Раз в сутки.

## Выключить робота

В 1С: «Онлайн магазин» → «Панель сайта» → снимите галочку «Instagram-консультант» → «Сохранить».
Действует через минуту, перезапуск не нужен. Сообщения, пришедшие пока робот выключен, он потом не подхватит —
на них отвечает сотрудник.

Галочка появится после обновления сервера и расширения 1С (03.10). До этого — удалите строку
`IG_ACCESS_TOKEN=...` из `/opt/sbonus/.env.production` и перезапустите сервер командой из шага 4.

## Ключ на 60 дней

Ключ Instagram живёт 60 дней. Робот сам продлевает его раз в сутки. Если робот замолчал и в журнале
`/var/log/sbonus-ig-bot.log` есть «Instagram 401» или «ключ не продлён» — создайте новый ключ (шаг 2, пункт 4)
и замените `IG_ACCESS_TOKEN` (шаг 4).
