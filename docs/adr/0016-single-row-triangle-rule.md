## Контекст

Проверка «рабочего треугольника» одинаково применялась к любой кухне. Ревью готовых кухонь показало, что для техники, стоящей в один ряд, треугольник вырождается в отрезок, и предупреждение получается не про реальное неудобство, а про саму форму кухни (прямая кухня в одну линию).

## Решение

Для кухни, где техника стоит в один ряд, треугольник — не мерило. Вместо него меряются соседние отрезки пути между техникой той же нормой ≤ 270, что уже используется в проверке, — без нового числа.

## Почему

- **Мерить соседние отрезки той же нормой ≤ 270.** Правило переиспользует уже существующий предел удобного расстояния вместо того, чтобы придумывать для линейной расстановки отдельный порог с нуля: число одно и то же для любой формы кухни, меняется только то, что́ именно меряется — стороны треугольника или соседние отрезки одного ряда.
- **Завести отдельный порог для кухни в один ряд.** Отвергнуто: два похожих по смыслу предела (для треугольника и для одного ряда) со временем разошлись бы, и их пришлось бы вручную держать согласованными при каждой правке проверки удобства.
- **Просто выключить проверку удобства для кухни в один ряд.** Отвергнуто: линейная кухня осталась бы вовсе без проверки на разумное расстояние между техникой, а готовые кухни и вообще кухни-эталоны должны быть без замечаний, а не без проверок.

## Последствия

- Проверка удобства теперь различает форму кухни (в один ряд или нет) и по-разному считает расстояние при одном и том же пороге — это разветвление нужно держать в уме при любой будущей правке проверки, иначе поправка может закрыть только одну из двух веток расчёта.
- Покупатели с обычной линейной кухней и готовые кухни в один ряд перестают получать ложные предупреждения о треугольнике — но код проверки стал сложнее и требует тестов на обеих ветках (в линию и не в линию).
- Порог ≤ 270 теперь общий для двух разных по смыслу измерений; если позже понадобится другое допустимое расстояние именно для одного ряда, решение придётся менять явно — сейчас оно сознательно совпадает с общим пределом и не должно молча разъехаться при следующей правке `dims.ts`.
