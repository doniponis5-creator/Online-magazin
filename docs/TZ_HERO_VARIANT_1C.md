# ТЗ для PC: выбор анимации баннера на главной из 1С

> Написано 01.10.2026 на MacBook (ветка `feature/ios-app`). Делает PC — там стоит 1С.
> Владелец: «shuni 1c dan ozgartirsa boladigan qilip berolesanmi?» — т. е. какую
> анимацию показывать на главной, владелец выбирает сам в 1С, без программиста:
> один вариант насовсем или «каждый день свой».

## 0. Что уже сделано на MacBook (в этой ветке, проверено)

**Сайт** — семь вариантов баннера «Дом просыпается» (шрифты, цвета, кнопки — одни и те же) и режим «по дням недели».
Владелец 01.10: «7 ta eng zo'rdan tanlaylik, harxil kunda o'zi alishib tursin» — семь лучших, каждый день сами меняются.
Вариант «утро → вечер» и «круг от кофемашины» владелец отверг — их нет.

| Код | Как называется в 1С | Что на экране | День в режиме auto |
|---|---|---|---|
| `auto` | Автоматически: каждый день свой | Вариант дня недели по времени Бишкека (колонка справа) | — |
| `reveal` | Окно и точки на технике | Кадр раскрывается из окошка во весь блок, камера идёт от кухни к стирке, на технике жёлтые точки-ссылки в разделы каталога | пн |
| `shutter` | Жалюзи | Кадр собирается из шести полос, которые приходят сверху и снизу | вт |
| `kitchens` | Готовые 3D-кухни | Колода из 7 готовых кухонь конструктора раскрывается веером, карточка открывает проект в конструкторе. Блок «Соберите свою кухню в 3D» ниже на главной при этом скрыт | ср |
| `collage` | Коллаж из фото техники | Снимки кофемашины, духовки, посудомойки, стиралки и робота разбросаны, как фото на столе, и слетаются в один кадр | чт |
| `marquee` | Бегущие слова | Позади бегут названия разделов, карточка кадра растёт до полного блока | пт |
| `word` | Слово «ДОМ» | Огромное «ДОМ» («ҮЙ» на кыргызском) с кухней внутри букв, камера пролетает сквозь слово | сб |
| `classic` | Классика (прежняя) | Сейчас на живом сайте: приближение кадра кухни, три фразы | вс |

Файлы: `src/lib/hero.ts` (коды, расписание недели), `src/components/StorefrontHero.tsx` (выбор),
`HomeStoryReveal.tsx` (reveal, shutter, collage, marquee, word), `HomeStoryKitchens.tsx`,
`home-story-reveal.css`, `home-story-kitchens.css`. Прежняя сцена `HomeStory.tsx` не тронута.

**Как сайт узнаёт выбор:** `src/app/[lang]/page.tsx` → `getHeroVariant()` (`src/lib/customer/gateway.ts`) →
`GET /api/v1/webhook/site/settings`, поле `heroVariant` → `resolveHero()` (для `auto` — вариант дня по Бишкеку).
Ответ кэшируется на 60 с (`callServer(..., { revalidate: 60 })`), главная пересобирается не чаще раза в минуту
(`export const revalidate = 60`). Выбор в 1С и смена дня доходят до сайта максимум за минуту.

**Умолчание — `auto`:** пустое значение, незнакомый код, старый сервер без поля, сервер не ответил → «по дням недели».
⚠ Значит, **выкладка сайта сама включает смену баннера по дням** — даже до того, как готово поле в 1С.
Так хочет владелец. Закрепить один вариант — выбрать его в 1С.

**Сервер** (`integrations/sbonus-server/shop/shop_admin.py`):
- в `SETTINGS` новая настройка `SITE_HERO_VARIANT`, тип `choice`,
  коды `auto / classic / reveal / kitchens / word / shutter / marquee / collage`, по умолчанию `auto`;
- `_clean()` понимает тип `choice`: незнакомый код → 422 «Анимация баннера на главной: допустимо …»;
- `GET /webhook/site/settings` отдаёт `heroVariant` (код как есть, `auto` сайт раскрывает сам);
- `GET /webhook/1c/shop/settings` отдаёт эту настройку в общем списке (с полем `choices`) — 1С её уже получает,
  но пока молча пропускает (ветка `Иначе` в цикле `ЗагрузитьНастройки`).

**Проверки:** `npx tsc --noEmit` — чисто; `npx vitest run` — 1065 из 1065, в том числе
`__tests__/hero-variant.test.ts` (коды сайта и сервера совпадают; умолчание `auto`; 7 дней — 7 разных вариантов;
день считается по Бишкеку, а не по времени сервера). Плавность на телефоне (390×844, процессор замедлен в 6 раз):
все семь — 60 кадров в секунду при прокрутке. Двигаются только transform и opacity, `clip-path` — только у `reveal`.

**Посмотреть локально без 1С** (только `npm run dev`): `http://localhost:3000/ru?hero=<код>`, например `?hero=collage`.
На собранном сайте этот параметр не работает.

## 1. Что нужно владельцу (как он это увидит)

1С → «Онлайн магазин» → «Панель сайта» → вкладка **«Настройки сайта»** — новое поле
**«Анимация баннера на главной»**, выпадающий список из восьми строк (таблица выше, колонка «Как называется в 1С»),
первая — «Автоматически: каждый день свой».
Выбрал → «Сохранить» → строка состояния «Настройки сохранены … Сайт применяет их сразу.» Через минуту главная — с новым баннером.

## 2. Что сделать в 1С (расширение `ИМ_ОнлайнМагазин`)

### 2.1 `integrations/1c-online-shop/build_extension.py`

1. Рядом с `PANEL_PROMO_TEMPLATES` — список названий (порядок = порядок в списке):
   ```python
   # «Настройки сайта» → анимация баннера. Коды для сервера — в ПанельСайтаМодуль.bsl (АнимацииБаннера).
   PANEL_HERO_VARIANTS = ["Автоматически: каждый день свой", "Окно и точки на технике", "Жалюзи", "Готовые 3D-кухни",
                          "Коллаж из фото техники", "Бегущие слова", "Слово «ДОМ»", "Классика (прежняя)"]
   ```
2. Реквизиты формы панели — рядом с `ЗаказБезВхода`:
   ```python
   f.attribute("АнимацияБаннера", t_str(40), title="Анимация баннера на главной", saved_data=True)
   f.attribute("АнимацияЗагружена", t_bool())
   ```
3. На странице `СтраницаНастройки`, в группе `ГруппаНастройки` — **третья строка** (в две существующие не влезет,
   см. комментарий там же про правый край):
   ```python
   f.group("ГруппаНастройкиБаннер", [
       f.input("АнимацияБаннера", "АнимацияБаннера", width=30, stretch=False, choices=PANEL_HERO_VARIANTS),
   ], direction="AlwaysHorizontal"),
   ```
   Кнопка «Сохранить» остаётся где была — одна на все настройки.
4. Версия расширения: `<Version>1.8.0.0</Version>` → `1.9.0.0`.

### 2.2 `integrations/1c-online-shop/src/ПанельСайтаМодуль.bsl`

1. `ЗагрузитьНастройки()` — в начале процедуры `АнимацияЗагружена = Ложь;`, в цикле по настройкам — ветка:
   ```bsl
   ИначеЕсли Ключ = "SITE_HERO_VARIANT" Тогда
       АнимацияБаннера = НазваниеАнимации(Значение);
       АнимацияЗагружена = Истина;
   ```
   После цикла: `Элементы.АнимацияБаннера.ТолькоПросмотр = НЕ АнимацияЗагружена;`
2. `СохранитьНастройкиНаСервере()` — отправлять **только если сервер эту настройку прислал**:
   ```bsl
   Если АнимацияЗагружена Тогда
       Значения.Вставить("SITE_HERO_VARIANT", КодАнимации(АнимацияБаннера));
   КонецЕсли;
   ```
   Почему: старый сервер (без `SITE_HERO_VARIANT`) на незнакомый ключ отвечает 422 «неизвестные настройки»
   и **не сохраняет ничего** — сломались бы и бонусы, и наценки. С флагом новая 1С работает и со старым сервером.
3. Функции перевода (названия ↔ коды; одна таблица, без дублей):
   ```bsl
   &НаСервере
   Функция АнимацииБаннера()
       Соответствие = Новый Соответствие;
       Соответствие.Вставить("auto", "Автоматически: каждый день свой");
       Соответствие.Вставить("reveal", "Окно и точки на технике");
       Соответствие.Вставить("shutter", "Жалюзи");
       Соответствие.Вставить("kitchens", "Готовые 3D-кухни");
       Соответствие.Вставить("collage", "Коллаж из фото техники");
       Соответствие.Вставить("marquee", "Бегущие слова");
       Соответствие.Вставить("word", "Слово «ДОМ»");
       Соответствие.Вставить("classic", "Классика (прежняя)");
       Возврат Соответствие;
   КонецФункции

   &НаСервере
   Функция НазваниеАнимации(Код)
       Название = АнимацииБаннера().Получить(Код);
       Возврат ?(Название = Неопределено, АнимацииБаннера().Получить("auto"), Название);
   КонецФункции

   &НаСервере
   Функция КодАнимации(Название)
       Для Каждого Пара Из АнимацииБаннера() Цикл
           Если Пара.Значение = Название Тогда
               Возврат Пара.Ключ;
           КонецЕсли;
       КонецЦикла;
       Возврат "auto";
   КонецФункции
   ```
   Названия должны **символ в символ** совпадать с `PANEL_HERO_VARIANTS` (там кавычки-ёлочки «ДОМ»).

## 3. Проверка на PC (до выкладки)

1. `python integrations/1c-online-shop/build_extension.py ut` → поставить **в тестовую копию** (`manage.py install test`).
2. Локальная копия сервера с новым `shop_admin.py` → «Панель сайта» → «Настройки сайта»:
   - поле показывает «Автоматически: каждый день свой» (умолчание сервера);
   - выбрать «Жалюзи» → «Сохранить» → `GET /webhook/site/settings` отдаёт `"heroVariant": "shutter"`;
   - перезапустить панель → в поле снова «Жалюзи»;
   - остальные настройки (бонус, %, наценки, WhatsApp) сохраняются как раньше.
3. Старый сервер (без этой правки) + новая 1С: поле серое (только просмотр), «Сохранить» работает, ошибки 422 нет.
4. Сайт локально в боевом режиме против локального сервера: выбор в 1С → через ≤ 60 с главная с новым баннером.

## 4. Выкладка (только с «да» владельца)

Порядок важен: **сервер → сайт → 1С**.
1. Сервер: новый `shop_admin.py`. Живой сервер владелец меняет сам — дать ему **одну команду с бэкапом**
   (правило: агент сам на живом сервере ничего не правит и не перезапускает). Миграции нет: значение лежит в той же таблице `settings`.
2. Сайт: обычная выкладка ветки. С этого момента баннер меняется по дням недели (умолчание `auto`).
3. 1С: расширение 1.9.0.0 в рабочую базу (`manage.py install prod`).
4. Владелец выбирает вариант в «Панели сайта». Вернуть как было — выбрать «Классика (прежняя)».

## 5. Не делать

- Не переводить коды в 1С на русский: сервер и сайт понимают только `auto / classic / reveal / kitchens / word / shutter / marquee / collage`.
- Не добавлять вариант только в одном месте. Новый вариант = `src/lib/hero.ts` + `choices` в `shop_admin.py`
  + `PANEL_HERO_VARIANTS` и `АнимацииБаннера()` в 1С (+ день в `HERO_WEEK`, если он входит в неделю).
  Тест `hero-variant.test.ts` ловит расхождение сайта и сервера.
