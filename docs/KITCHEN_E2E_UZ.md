# Ошхона конструктори — браузерда текшириш (e2e)

Сана: 30.09.2026. Playwright (браузерни ўзи бошқарадиган дастур) конструкторни
икки профилда — телефон ва компьютер — бошидан охиригача босиб чиқади.

## Қандай ишга туширилади

Аввал dev-сервер (сайтнинг ишчи нусхаси) 3001 портда турган бўлсин:

```bash
npx next dev --webpack -p 3001
```

Кейин, лойиҳа папкасидан — конструкторнинг ҳамма тестлари, учала профилда (62 тест, ~3 дақиқа):

```bash
PW_BASE_URL=http://localhost:3001 npx playwright test e2e/kitchen-gestures.spec.ts e2e/kitchen-plan.spec.ts e2e/kitchen-phone.spec.ts e2e/kitchen-simplify.spec.ts e2e/kitchen-acceptance.spec.ts
```

30.09.2026 натижа: 60 ўтди, 2 ўтказиб юборилди (компьютер ва кадр тестлари iPhone
профилида ишламайди — шундай мўлжалланган). `npx playwright test` файлсиз — сайтнинг эски
тестларини ҳам (`cart`, `catalog`, `checkout`, `visual` …) юритади; улар dev-серверга эмас,
`npm run build && npm run start` (3100 порт) га мўлжалланган.

Фақат конструктор, фақат бир профил:

```bash
PW_BASE_URL=http://localhost:3001 npx playwright test e2e/kitchen-acceptance.spec.ts --project=iphone
PW_BASE_URL=http://localhost:3001 npx playwright test e2e/kitchen-acceptance.spec.ts --project=desktop
```

Бир марта WebKit браузерини ўрнатиш керак (iPhone профили учун, npm пакет эмас):

```bash
npx playwright install webkit
```

`PW_BASE_URL` берилмаса, Playwright ўзи `npm run start` билан 3100 портда сайтни
кўтаради (аввал `npm run build` керак).

## Нима текширилади (`e2e/kitchen-acceptance.spec.ts`)

1. **Мижоз йўли:** тайёр ошхона → «Техника» да духовка → «Итог» → «Всё в корзину»
   (савaтга қўшилди, ҳисоб кўринди) → «Открыть лист мастера» — ўша ошхона алоҳида саҳифада.
2. **Етти белги (reference.md):** тепадан план 3D ёнида · бўш жой билан эркин қўйиш
   (силжитганда автоматика бўш жойни ёпмайди) · «+» дан каталог (техника ва шкаф) ·
   шкаф бармоқ орқасидан юради (ушлаган нуқта сақланади) · битта қоида: тап — танлаш,
   танланмаганни тортиш — айлантириш, иккинчи бармоқ — бекор · телефонда 3D ярим экран
   ва пастки панель · мижоз ва уста саҳифалари алоҳида.
3. **12 тайёр ошхона ва 5 эски манзил** очилади ва планнинг катаклари
   `e2e/__snapshots__/kitchen-acceptance.spec.ts/*.txt` даги суратга тенг. Сурат икки
   профил учун битта: телефон ва компьютер бир хил ошхона беради. Модель даражасидаги
   сурат — `__tests__/kitchen-layout-snapshot.test.ts` (vitest).
   Раскладка атайлаб ўзгарса: `npx playwright test e2e/kitchen-acceptance.spec.ts --update-snapshots`.
4. **Духовка — 3 тадан кўп босмасдан** (`__tests__/fixtures/kitchen-live-appliances.json`
   фикстурасида — жонли каталогда — духовкалар бор; локал каталогда ҳам биттаси бор).
5. **Компьютер 1440 × 900:** план + 3D ёнма-ён, созламалар панели ≥ 440 px, саҳна пастини
   ҳеч нарса ёпмайди (пастки панель йўқ, консультант саҳнадан ташқарида).
6. **Тезлик (фақат `desktop`, Chrome):** телефон ўлчами 375 × 812, процессор CDP орқали
   4 марта секинлаштирилади (`Emulation.setCPUThrottlingRate`), 3 секунд ошхона
   айлантирилади; кадр = движокнинг `draw()` чақируви. **Чегара: ўртача кадр ≤ 33 мс**
   (30 кадр/с, R06). 30.09.2026 да MacBook да ўлчов: ўртача 16,7 мс, p95 17,7 мс,
   3 секундда 180 кадр, класс `phone`.

## Изоҳлар

- Тестлар движокка dev-йиғмадаги `window.__kp` орқали қарайди (`placeOf`, `screenPointOf`,
  `lastDrag`, `getTier`); production йиғмада бу йўқ — шунинг учун dev-сервер керак.
- Бармоқлар — сунъий `PointerEvent` (Playwright иккинчи бармоқни билмайди).
- `npx next build` ва dev-сервер бир `.next` папкасини ишлатади: build кетаётганда e2e юритманг —
  саҳифалар ўз-ўзидан қайта юкланиб, тестлар тасодифан йиқилади (build тугагач яна яшил).
- Кадр ўлчови MacBook нинг ўз видеокартасида: 16,7 мс = экран 60 Гц чегараси, яъни процессор
  4 марта секин бўлса ҳам JS ва ҳисоблар кадрни ушлаб қолмаяпти. Ҳақиқий арзон телефоннинг
  видеокартаси бошқа — бу тест фақат процессор томонини ушлайди.
- Локал `src/data/1c/catalog.json` эски: холодильник, посудомойка, варочная йўқ. Тайёр
  ошхоналардаги шундай техника локалда бўш қолади — бу тестга халақит бермайди, суратлар
  шу каталогга олинган.
