# Сайт кўп одамга чидаши (08.10.2026, рекламадан олдин)

## Нима эди

26.09 даги синов: сайт бир вақтда ~250–300 кишига чидарди.

- **SBonus чегараси.** SBonus бир манзилдан 10 сонияда 200 та сўров қабул қилади. Сайт эса ҳар бир экранда SBonus'га иккита сўров юборарди: сайт созламалари ва ташриф ҳисоби. Кўп одам кирса, SBonus сайтни 10 сонияга тўхтатарди: кириш, бонус ва заказ ишламасди.
- **Сайт сервери (Node).** Секундига ~185 сўров, яъни тахминан 500 киши.

## Нима қилинди

1. **Сайт созламалари** энди 1 дақиқа сайт хотирасида туради. SBonus'га дақиқасига 1 та сўров кетади, ҳамма учун битта (`src/lib/customer/gateway.ts` `getSiteSettings`).
2. **Ташрифлар** йиғилиб, 5 сонияда бир пачка бўлиб кетади (SBonus `POST /webhook/site/visits`). Илгари ҳар бир экран учун алоҳида сўров эди.
3. **Cloudflare (сайт олдидаги тезлатувчи хизмат)** оддий саҳифаларни (бош саҳифа, каталог, товар) 30 сония ўзида сақлаб бериши мумкин. Сайт буни `Cloudflare-CDN-Cache-Control: max-age=30` белгиси билан айтади (`next.config.ts`). Заказ, галерея, API ва панелга бу белги қўйилмаган.

4. **Товар расмлари** браузерда энди сайт орқали очилади (`/p/…`). Cloudflare ҳар бир расмни бир йил сақлайди, SBonus сервери уни фақат бир марта беради. Заказлар, 1С ва бот ишлайдиган сервер юкдан қутулади (`src/lib/photoSrc.ts`, `next.config.ts` rewrites).
5. **«Ким кирди» текшируви.** Кирмаган меҳмон учун у ҳар бир саҳифада эмас, вкладкада бир марта юборилади (`src/lib/customer/loginHint.ts`). Илгари ҳар бир экранда сайт серверига сўров кетарди.

## Тартиб (муҳим!)

1. Сервер:
   ```bash
   powershell -ExecutionPolicy Bypass -File scripts/deploy-all.ps1 -Server
   ```
2. Сайт:
   ```bash
   powershell -ExecutionPolicy Bypass -File scripts/deploy-all.ps1 -Site
   ```
3. **Фақат сайт янгилангандан кейин** Cloudflare қоидасини ёқинг (пастда). Аввал ёқилса, каталог эски нарх билан бир йил Cloudflare'да қолиши мумкин.

## Cloudflare қоидаси (5 дақиқа)

1. dash.cloudflare.com → **smarket.kg** → чапда **Caching** → **Cache Rules** → **Create rule**.
2. Rule name: `Сайт саҳифалари 30 сония`.
3. **If incoming requests match…** → **Custom filter expression** → **Edit expression** ва шуни қўйинг:
   ```
   (http.host eq "smarket.kg" and not starts_with(http.request.uri.path, "/api/") and not starts_with(http.request.uri.path, "/panel"))
   ```
4. **Then…**
   - Cache eligibility: **Eligible for cache**
   - Edge TTL: **Use cache-control header if present, bypass cache if not**
   - Browser TTL: **Respect origin**
5. **Deploy**.

Текшириш: сайтни 2 марта очинг. Иккинчи сафар `cf-cache-status: HIT` чиқиши керак. Буни Claude текшириб беради.

Ўчириш керак бўлса: шу қоидани **Disable** қилинг. Сайт аввалгидек ишлайди.

## Рекламадан олдин: расмларни Cloudflare'га юклаш

Cloudflare қоидаси ёқилгандан кейин бир марта ишга туширинг (5–10 дақиқа):
```bash
node scripts/warm-photos.mjs
```
Скрипт каталогдаги ҳамма расмни секин юклайди, секундига 5 та. Шунда рекламадан келган биринчи мижозлар SBonus'ни юкламайди.
