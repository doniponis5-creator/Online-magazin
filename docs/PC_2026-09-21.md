## Что работает (выкачено)

| Что | Где | Коротко |
|---|---|---|
| Рассрочка в чате | `shop_installments*.py`, 1С `ОтправитьРассрочкуНаСайт` | Долг только вошедшему (cookie) или по номеру WhatsApp. Номер у 2+ разных клиентов — «общий», цифр не называем |
| Знания от владельца | 1С «Панель сайта» → «Знания для чата», `notes.ts`, таблица `shop_assistant_notes` | Часы, гарантия, возврат — **владелец ещё не заполнил** |
| Каталог «по вопросу» | `knowledge.ts catalogForQuestion` | 25 товаров целиком + весь каталог строками |
| Продавец | `prompt.ts` «КАК ПРОДАВАТЬ» + «ОБРАЗЦЫ» | Уточнить → 1–2 варианта с выгодой → «Оформим? «беру»». Бюджет режет код (`budget.ts`), «дорого» — только дешевле |
| Заказ прямо в чате | `respond.ts` + `telegram/order.ts` | Кнопка «Заказать» у карточки, «беру», «да» → ссылка O!Деньги кнопкой |
| «Перезвоните» | `leads.ts`, сервер `POST /webhook/site/lead` | Номер + пересказ → WhatsApp владельцу, раз в 10 мин с номера |
| Ответ модели — JSON | `gemini.ts`, `answer-json.ts` | Размышления модели покупателю не уходят; id товаров вырезаются |
| Приветствие | везде | «Ассаламу алейкум», кыргызский первым в списке языков; отвечает на языке покупателя |
| Мобильный чат | `AssistantChat.tsx`, `assistant-chat.css` | До 560 px — во весь экран над клавиатурой, 16 px поле |
| Гарантия | 1С карточка «Гарантия, мес.», сайт `ProductPurchase.tsx` | Плашка со щитом «Гарантия 1 год — на заводской брак» |
| «В наличии» без числа | `adapter.ts stockHidden` | «По остатку» — настоящее число, «В наличии» — без него |
| Бронь последней штуки | `shop_stock.py` | Остаток = 1С − оплаченные/ждущие заказы, о которых 1С не знает. «В наличии» не ограничивается (решение владельца) |
| Товары не с сайта | 1С `ОтправитьТоварыДляЧата`, `shop_chat_extra`, `live.ts salesCatalogNow` | Чат продаёт со склада то, чего нет на сайте. Цена = себестоимость + наценка (крупная 15%, мелкая 20% — «Панель сайта»). Себестоимость из 1С не уходит |
| «Оплачено — нужно действие» | `shop_admin.py _attention`, 1С Панель сайта | Оплачено, а товара нет / не попал в 1С / 1С не забирает |
| **WhatsApp-продавец** | `shop_wa_bot.py`, cron `/etc/cron.d/sbonus-wa-bot` | См. ниже |

## WhatsApp-продавец (новое, проверено вживую)

- Номер магазина **+996 557 100 505** (Green API instance 7105189394).
- **Webhook не подключён намеренно**: очередь уведомлений читает WhatsApp-чат в 1С
  («СистемаВзаимодействия»). Сервер раз в минуту читает **журналы** Green API.
- В Green API владелец включил «входящие» и «отправленные с телефона». URL пустой — **так и оставить**.
- Логика: сообщение → ждём 5 мин (`SITE_WA_DELAY_MIN`) → сотрудник не ответил → отвечает
  мозг сайта (`/api/channel/whatsapp`): текст + фото с ценой и ссылкой. Дальше, пока
  сотрудник молчит, — через минуту. Сотрудник написал — робот молчит 12 ч.
  30 ответов человеку в сутки. Автоответ WhatsApp Business не считается сотрудником.
- Модель недоступна — робот в WhatsApp **молчит** (шаблоны не шлёт).
- Голосовое — через те же 5 минут робот пишет по-русски: «Извините, голосовые сообщения я не слушаю — напишите, пожалуйста, текстом» (не чаще раза в 30 минут на чат).
- Журнал: `/var/log/sbonus-wa-bot.log` (пишет только «ответил: N» и ошибки).
- Выключатель: 1С «Панель сайта» → «WhatsApp-консультант» (после установки 1С завтра).

## Ждёт завтра (PC, 1С)

1. `python integrations/1c-online-shop/manage.py install test`, затем `install prod`.
   В этой версии: гарантия в карточке, товары для чата с наценкой, две наценки,
   переключатель WhatsApp, исправления (новый покупатель, отгрузки по списку сервера,
   закрытый заказ не отгружается сам, партнёр по имени при общем номере).
2. Владельцу: заполнить «Знания для чата»; выключить автоответ WhatsApp Business;
   поставить настоящую цену **LEVO LV-70DG2T (сейчас 1 сом!)**.

## Прочее

- **Gemini**: платный Tier 1, предоплата. Кредит закончится — чат на шаблонах, WhatsApp молчит.
  Бесплатный лимит больше не действует. Модель — Flash-Lite (решение владельца).
- **Токен Green API** частично попал на скриншот в чате. Сменить при случае (нужен
  скрипт со скрытым вводом, как `scripts/setup-telegram-gateway.ps1`).
- Проверки перед выкатом: `npx tsc --noEmit`, `npx vitest run` (121 тест), `npm run build`.
- Выкат с Windows: сервер — копия `integrations/sbonus-server/shop` **без CRLF**
  (`tr -d '\r'`) в `/tmp/sb_shop`, затем `bash /tmp/sb_shop/deploy_shop.sh`; сайт —
  `bash deploy/site/pack.sh` + `update_site.sh`.
