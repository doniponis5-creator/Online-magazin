## Вход через WhatsApp «наоборот» (главное за вечер)

| Что | Где |
|---|---|
| Сервер | `shop_customers.py`: `POST /wa-login/start` (код + номер магазина из Green API `getSettings.wid`), `POST /wa-login/check` (читает `lastIncomingMessages`, ищет `WA_LOGIN_RE`, подтверждает отправителя) |
| Бот | `shop_wa_bot.py`: сообщения «Код входа: …» продавцу не отдаются |
| Сайт | `gateway.ts waLoginStart/waLoginCheck`, `/api/customer/wa-login/start|check`, `CustomerLogin.tsx` шаг `wa` (опрос раз в 3 с, до 5 мин) |
| Проверено | в тестовом режиме в браузере: кнопка → wa.me с текстом → «ждём» → анкета имени → кабинет с 1 000 сом |

## Для PC: кабинет SBonus тоже шлёт код через Green API

`cabinet.smartcentr.store` (контейнер `client`, бэкенд `/opt/sbonus/sbonus-backend/app`,
кода в этом репозитории нет) на входе отправляет 4-значный код в WhatsApp — тот же
риск блокировки. Владелец выбрал: добавить туда «Вход через WhatsApp наоборот».

Сделано с Mac: `integrations/sbonus-server/cabinet/` — `patch_backend_walogin.py`
(два эндпоинта в `customer_auth.py`), `patch_client_walogin.py` (кнопка на
`/login` + `lib/api.ts`), `deploy_cabinet_walogin.sh` (бэкапы, пересборка api и
client, откат). Кода кабинета в репозитории по-прежнему нет — патчи применяются
к файлам на сервере и повторный запуск ничего не ломает.

Что переиспользовано из `app/shop/shop_customers.py`:
`_own_wa_number()` — номер магазина из Green API; `_scan_wa_logins()` — читает
`lastIncomingMessages` и отмечает `shop_walogin_done:{code}` → телефон;
`WA_LOGIN_RE` — текст сообщения; ключи Redis `shop_walogin:{code}` (ttl 300).
Нужно в ядре: два эндпоинта для кабинета (start → код + номер; check → pending |
сессия кабинета по телефону) и кнопка на странице входа `client` (wa.me с текстом
«Код входа: 482913», опрос раз в 3 с до 5 минут). Старый код по WhatsApp оставить
как запасной — свёрнутым.

**Не проверено вживую** (нужен сервер): что Green API отдаёт `wid` и что
`lastIncomingMessages` видит сообщение за секунды. В 1С-чате WhatsApp эти
сообщения будут видны сотрудникам — это нормально.

0. Открыть smarket.kg/ru/account с телефона → «Войти через WhatsApp» → отправить
   готовое сообщение → через 3–10 секунд сайт должен войти сам.

   5 минут — робот должен ответить по смыслу. Журнал: `/var/log/sbonus-wa-bot.log`.
2. `docker exec sbonus_api python3 -c "from app.shop.shop_wa_bot import send_digest; import asyncio; asyncio.run(send_digest('2026-09-21'))"` —
   сводка должна прийти владельцу.
3. Открыть чат на smarket.kg, нажать камеру, прислать фото товара.
