## P0 — исправления поведения

### 1. Язык (Header.tsx) — ИСПРАВЛЕНО
- Переключение языка теперь строится через чистый `buildLangHref(pathname, search, next)`
  (`src/lib/links.ts`): только внутренние `/ru/...` и `/ky/...`, `//...` невозможно по
  построению; query-параметры поиска/фильтров сохраняются.
- Корректные aria-label: текущий язык «Язык интерфейса: русский» /
  «Интерфейс тили: кыргызча», переключатель — «Переключить на кыргызский» / «Русчага ўткөрүү».
- Проверено e2e: `cart.spec.ts › language switch RU→KY preserves cart and stays on the same host/path`
  (главная → корзина → товар; корзина и избранное не исчезают, хост не меняется).
- Регресс-тесты: `links.test.ts` (6 тестов, включая запрет `//`-ссылок и сохранение query).

### 2. Каталог (CatalogView.tsx, Header.tsx) — ИСПРАВЛЕНО
- URL — единственный источник состояния: `q`, `cat`, `brand`, `sort` читаются из
  `useSearchParams`, изменения пишутся `router.push`. Initial-props убраны — повторная
  навигация больше не «застревает» на старых результатах.
- Назад/вперёд, reload, ссылки категорий и поиск из шапки восстанавливают вид
  (найденная по ходу ошибка: фильтры писались через `router.replace` и «съедали» историю —
  переведены на `push`; поле поиска шапки при загрузке `/catalog?q=...` показывает активный запрос).
- e2e: `catalog.spec.ts` — 4 сценария: поиск из шапки дважды (Aura → AirSound),
  категория + сортировка + бренд, назад/вперёд, reload, сброс фильтров, empty-state.

### 3. Корзина (CartProvider.tsx, logic.ts) — ИСПРАВЛЕНО
- `normalizeLines()`: восстановленные данные приводятся к валидному виду — известный
  товар/вариант, целое qty > 0, зажим до демо-остатка, слияние дубликатов SKU,
  отбрасывание мусора; повреждённый JSON не падает и не даёт отрицательных/NaN сумм.
- Понятное сообщение при корректировке: «Корзина восстановлена с изменениями…» /
  «Себет өзгөртүлүп калыбына келтирилди…» (закрываемый `.notice`).
- Hydration: checkout/корзина до восстановления показывают нейтральный заголовок,
  без мигания ложной пустоты и без ложных форм.
- Синхронизация вкладок через `storage`-событие (приходит только из других вкладок —
  циклов записи нет). Персональные данные в localStorage не пишутся.
- e2e: `cart.spec.ts` — добавление варианта, зажим количества (min-max), пересчёт,
  удаление, reload; `corrupted localStorage is normalized` (дубликаты + неизвестные id +
  отрицательные qty + остаток 0).

### 4. Варианты и галерея (ProductDetail.tsx, Gallery.tsx, sku.ts, products.ts) — ИСПРАВЛЕНО
- Один источник выбранного SKU: `ProductDetail` хранит цвет+память и вычисляет
  конкретную комбинацию (`comboVariant`); галерея, цена, остаток, alt/aria и добавление
  в корзину читают один и тот же вариант. Fallback на невыбранный SKU исключён
  (`comboVariant` возвращает undefined для несуществующей комбинации — покрыто тестом).
- Модель данных переведена на комбинации «цвет + память» (`colorOptions`/`memoryOptions`);
  несуществующие/недоступные комбинации не продаются: `out-of-stock SKU: selectable chip
  does not allow purchase` (e2e). Авто-подбор ближайшей доступной комбинации при смене
  измерения (`pickMemoryForColor`/`pickColorForMemory`, юнит-тесты).
- Зум: `.gallery__main--zoom` открывает диалог, Escape и крестик закрывают, фокус
  возвращается на opener — e2e `product gallery zoom: open → Escape → close → focus returns` PASS.
- Локализованные alt/title/aria (RU/KY) для галереи и вариантов.
