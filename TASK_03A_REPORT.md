## 2. Четыре пункта ревью — что сделано и чем доказано

1. **Неверная категория изображения (tablet.jpg — часы).** Товарные фото
   удалены из интерфейса полностью; файл `public/photos/tablet.jpg` сохранён
   в архиве с честной пометкой «на снимке смарт-часы, а не планшет — снят
   с витрины» (`photo-sources.ts`, `/sources`, metadata). Признаю: моё
   утверждение в прошлом отчёте «планшет целиком на белом» было ошибкой
   визуальной проверки.
2. **Кеш баннеров (новые файлы / старые скриншоты).** Причина подтверждена:
   производный кеш next/image живёт по неизменному URL `public/photos/*.jpg`,
   замена содержимого по тому же URL отдаёт старую копию из `.next/cache`.
   Решение структурное: в промежуточной итерации баннер был переведён на
   статический импорт (`src/assets/hero-blue-lime.<hash>.jpg` — байтовое
   сравнение отданного ассета с исходником совпало, sha256 идентичен), затем
   по brief LG фотография из hero ушла вовсе — сцена теперь целиком CSS,
   сетевых изображений в баннере нет, и класс проблемы исчезает по
   определению. Все снимки в `review/task-03a/` перегенерированы из той же
   сборки, которая сдаётся (сервер перезапущен после финального build).
3. **CSS reduced-motion перенесён физически.** Блок
   `@media (prefers-reduced-motion: reduce)` реально стоит в самом конце
   `globals.css` (после `.reveal` и всех правил сцены; до этого он был на
   строке 2168 при `.reveal` на 2394). Проверено не только классами:
   e2e-тест читает **computed opacity** секции с добавленным `.reveal`
   без `.is-in` → `1`; при загрузке с reduce computed transform группы
   машины не меняется при прокрутке, `transform` stage = `none`; при
   переключении настройки на лету все секции раскрываются.
4. **Нестабильная регрессия (task03a:100).** Причина: проверка считала
   `pending.count()` до регистрации наблюдателя и в контексте с наследуемой
   системной настройкой. Исправлено без sleep/retries/отключения: контекст
   создаётся с явным `reducedMotion: 'no-preference'`, scroll к началу,
   ожидание готовности через `waitForFunction` (секции зарегистрированы и
   ждут вьюпорта), переключение `emulateMedia` + `expect.poll`. Полный
   набор прогнан дважды подряд (40/40, 40/40) + целевые повторы motion-тестов
   `--repeat-each 3` (12/12) под параллельной нагрузкой — стабильно.

## 3. 3D-сцена LG F4X5ES5SB (обновление 12.09)

Реализация — чистый CSS 3D (perspective/transform, без WebGL и библиотек:
тяжёлая зависимость ради одного баннера не обоснована, а требуемый объём
CSS даёт). `Hero3D.tsx` + блок `.hero3d/.wm` в `globals.css`.

- **Короткий sticky-участок** (~560px сцены + 460px диапазона на desktop;
  500px + 340px на мобильном): обычная прокрутка двигает прогресс `--p`
  через rAF; wheel/touch не перехватываются, каталог доступен сразу по CTA.
- **Фазы** (рампы clamp/min от `--p`, смена текстов — кроссфейд в одной
  grid-ячейке, «виснущих» заголовков нет):
  1) машина в ракурсе 3/4 (серебристый корпус, чёрная панель, тёмное стекло
     люка, контактная тень) + «LG F4X5ES5SB · 11 кг»;
  2) крупный барабан с «бельём» и четырьмя стилизованными потоками —
     TurboWash™360° («вода и моющее средство в четырёх направлениях»);
  3) вид сзади: схема прямого привода (вал, мотор-«катушки», пунктир) —
     Inverter Direct Drive; внутренние виды подписаны «Схематичная
     демонстрация технологии» / «Технологиянын схемалуу көрсөтүүсү»;
  4) машина собирается, акценты «AI DD · 11 кг · ThinQ», CTA «Смотреть
     стиральные машины».
- Барабан/потоки вращаются CSS-анимацией (замедляются при reduce).
- **Pointer-tilt** — только тонкий указатель и только декоративная сцена;
  текст/CTA вне сцены, клики стабильны; на touch отключён.
- **Fallback**: без JS `--p` не задан → каскад показывает собранную машину
  со всеми текстами и CTA (элементы в SSR-HTML); при reduce дополнительно
  фиксируются фазы (интро), вращение и лишняя высота скролл-диапазона.
- Мобильная композиция отдельная: сцена компактнее (упрощённые слои,
  уменьшенный диапазон), текст и кнопки не перекрываются, нижняя навигация
  свободна.

## 6. Ограничения (честно)

1. Сцена — стилизованная демонстрация, не заводская CAD-реконструкция LG
   (внутренние виды подписаны как схема). Фотореализм не заявляется.
2. Профессионального замера fps нет и чисел плавности я не привожим;
   плавность обоснована только устройством (transform/opacity в rAF,
   passive scroll) и визуальной проверкой записи.
3. Кадры из webm отдельно не извлечены (ffmpeg в окружении отсутствует);
   кадровое доказательство изменений сцены — триптихи PNG + computed
   transform в тесте.
4. Товарные фото появятся только от владельца (реальные модели/артикулы);
  до тех пор карточки — единый плейсхолдер. Аэрогриль и ранее был SVG.
5. Это прототип: 1С/SBonus/платежи не подключены; LG показана как
  промо-демо технологии без цены/остатка/оплаты.
